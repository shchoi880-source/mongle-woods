## 실행 방법
- `node tools/serve.js` → http://127.0.0.1:8765/ (`?dev=1` 붙이면 디버그 패널: 시간 이동·날씨·몽)
- `node tools/verify.js [시드 수]` → 데이터·월드 생성·세이브 왕복·마이그레이션 검증

## 조작
- PC: 방향키/WASD 이동, Shift 달리기, C 살금, Space/E 행동, Q 도구 바꾸기, Tab 잎첩, Esc 닫기, 마우스 클릭(가까운 곳) 행동
- 폰: 화면 왼쪽을 끌어서 이동(살짝 = 살금, 끝까지 0.25초 = 달리기), 오른쪽 아래 노란 버튼 = 행동, 옆 버튼 = 도구

## 개발 방식 (오너 요청)
- 오너는 PC와 폰을 오가며 플레이하고 개발도 한다. **모든 기능은 마우스·키보드와 터치 양쪽에서 동작**해야 한다(새 기능마다 PC·폰 두 화면으로 테스트).
- 작업은 작게 쪼개 자주 커밋·푸시하고, 푸시 전에 `git fetch`로 다른 기기 작업이 없는지 확인한다.

## 메모
- 버그 수정(테스터 제보): ①게시판·벤치 그림 잘림 — 두 칸짜리 소품을 64px 판에 그려 오른쪽이 잘리고 16u 밀려 있었음 → 96px 판·위치 보정 ②삽 아이콘이 곡괭이(⛏️ 이모지) → 도구 아이콘은 전부 직접 그린 그림 사용(이모지는 기기마다 달라 금지)
- 버그 수정 기록: 폰에서 버튼으로 창을 열면 뒤따르는 클릭이 배경에 떨어져 창이 바로 닫히던 문제 → 배경을 직접 눌렀다 뗄 때만 닫힘(js/ui.js modal).
- 파일 구조는 r2-기술 §2의 70개 파일 분할 대신, 1인 구현에 맞게 **같은 G 계약을 따르되 파일을 묶었다**(js/*.js 16개). 팀이 늘면 그때 쪼갠다.
- 첫날 대본: 보리 할멈은 편지만 주고, 낚싯대는 소금이·잠자리채는 라임이 첫 만남에 준다(r2-재미 §3-1 원안).
- 새 주민 집(house2·3)은 월드 생성 맨 끝에 덧붙여서, 기존 세이브의 지도는 그대로다.
- 세이브 키: `mg.slot.A/B`, `mg.meta`, `mg.premig`, `mg.settings` (r2-기술 §3.1).
