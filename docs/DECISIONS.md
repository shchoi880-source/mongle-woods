# 오너 결정 기록

r2-제작범위 §6의 8건. 오너 답이 오기 전까지 **패널 권고안으로 임시 확정**하고 진행한다. 바뀌면 이 표와 코드(`js/data.js`의 문자열 등)를 함께 고친다.

| # | 결정 | 현재 적용 | 상태 |
|---|---|---|---|
| D1 | 화폐명 | **몽 (◎)** | 임시 확정 |
| D2 | 화면 방향 | **반응형** (폰 세로 기본·가로 허용, PC 가로) | 임시 확정 |
| D3 | 대외 수량 표기 | "곤충 200종, 도감 1,200칸" 식 | 베타 후 |
| D4 | 타이틀 | **몽글숲 이야기 (Mongle Woods)** | 임시 확정 |
| D5 | 베타 일정 | W8 겨울 프리뷰 + W12 봄 공개 베타 | 임시 확정 |
| D6 | 둥근 한글 폰트 | 베타에 도입 예정. M-a는 시스템 폰트 | 보류 (폰트 파일 선정 필요) |
| D7 | 바다생물 | 조수 웅덩이 4 + 간이 잠수 16 | M-b에서 구현 |
| D8 | 이야기 톤 | 단풍 미스터리 + 설득형 이사 | M-b 이후 |
