# 1차 회의 제안서 — 월드·맵 팀 + 시간·생태 팀 (합동)

- 참석: 월드·맵 **한결**(구현) / **서윤**(검토), 시간·생태 **도현**(구현) / **미르**(검토)
- 범위: 맵 생성·렌더·충돌, 맵 오브젝트와 매일 리스폰, 실시간 시계·계절·날씨·조명, 곤충/물고기 스폰·포획, 화석·발굴, 월드 저장
- 표기: "타일" = 논리 16×16px. 월은 북반구 기준(남반구 = +6개월). 시간은 0~23시, `19-4`는 19:00~03:59.
- 통화명은 시스템·경제 팀 결정 전까지 **"코인(가칭)"**으로 쓴다. 가격 칸은 제안값이며 최종 결정은 경제 팀.

## 0. 쟁점과 토론 기록 (요약)

| # | 쟁점 | 의견 A | 의견 B | 합의 |
|---|---|---|---|---|

## 1. 맵

### 1.1 규격
- 맵: **112 × 96 타일**(1792×1536 논리 px). 바깥 테두리 4타일은 통과 불가(바다/절벽/울타리 숲).
- 타일: 논리 **16px**, 화면 배율은 정수 배율 자동(폰 세로 기준 가로 약 15~17타일 보이게: 배율 = floor(화면폭/16/16), 최소 2). 화면 흔들림·카메라 lerp 0.15.
- 높이: **레벨 0(해변·저지대) / 1(마을 중심) / 2(북쪽 고지대)**. 절벽 1단 = 화면상 16px 높이 + 아래쪽 절벽면 타일.

### 1.2 레이어 (타일 1칸 = 1바이트 패킹 + 오브젝트 희소맵)
| 레이어 | 저장 형식 | 값 |
|---|---|---|
| ground | 3bit | 0 잔디, 1 흙길, 2 모래, 3 젖은모래(파도선), 4 돌바닥(광장), 5 밭흙(로드맵), 6 다리 |
| height | 2bit | 0 / 1 / 2, 경사로는 ground와 별개 플래그 |
| water | 3bit | 0 없음, 1 강, 2 강 하구, 3 연못, 4 바다, 5 폭포, 6 얕은물(로드맵 수영) |
| flags (런타임 계산) | Uint8Array | bit0 통행불가, bit1 경사로, bit2 절벽면, bit3 건물부지, bit4 낚시가능 물가 |
| objects | `Map<idx, Obj>` | 나무·바위·꽃·잡초·조개·발굴지점 등 (2장) |

### 1.3 시드 기반 절차 생성 (`worldgen.js`, 결정적, mulberry32 + 하위 스트림)
1. **시드**: 새 게임 시 `seed = (Date.now() ^ Math.random()*2^32) >>> 0`. 하위 스트림 `rng('river')`, `rng('forest')`…로 분리해 단계 추가 시 다른 단계 결과가 바뀌지 않게 한다.
2. **해변(남쪽 고정)**: y = 84~95 영역. 1D 값 노이즈로 해안선 y = 86±2, 모래폭 6~8타일, 그 아래 바다. 해변 양끝에 바위 곶 1개씩.
3. **절벽 2단**: 경계선 y₁ ≈ 30±4(레벨2/1), y₂ ≈ 60±3(레벨1/0)을 1D 노이즈(주기 24타일)로 구불구불하게. 각 경계에 **경사로 3개**(2타일 폭, 서로 최소 20타일 간격). 절벽 모서리는 마칭 스퀘어 16종 오토타일.
4. **강**: 북쪽 테두리 x ∈ [30, 82]에서 시작, 아래로 랜덤워크(매 스텝 x 드리프트 −1/0/+1, 관성 0.7), 폭 3(레벨2는 2). 절벽 경계를 지나는 지점은 **폭포**. y ∈ [40, 64]에서 **지류 1개** 분기(폭 2, 대각 진행) → 50% 본류 재합류 / 50% 연못 또는 바다로. 하구는 폭 4~5로 넓혀 바다와 연결.
5. **연못 2~3개**: 반경 3~5 원에 셀룰러 오토마타 3회(모양 다듬기). 강·절벽·부지에서 3타일 이상 떨어지게, 레벨당 최대 1개 + 레벨1에 반드시 1개.
6. **광장·부지**: 레벨1 중앙부(강에서 4타일 이상)에 **광장 10×8**(돌바닥). 광장 인접에 **상점 부지 8×6, 박물관 부지 8×7, 안내소(시작 텐트) 6×5**. **주민 집 부지 8개(5×5)**와 **플레이어 집 부지 1개(6×6)**를 레벨0~1에 포아송 배치(부지 간 최소 3타일). 모든 부지 문 앞 2타일은 흙길 연결 보장.
7. **다리**: 강이 광장↔해변, 광장↔서/동측을 가르는 곳에 **초기 다리 2개**(본류) + 지류 1개. 로드맵에서 다리 건설 시스템.
8. **숲**: 노이즈 밀도 마스크(레벨2 0.55, 레벨1 0.25, 레벨0 0.12, 해변 0.05 야자) × 포아송 디스크(최소 간격 2타일). 부지·길·광장·물가 1타일 안에는 금지. 목표 나무 수 **260~320그루**(과일나무 6그루는 플레이어 집 근처 보장).
9. **바위 6개, 꽃 무리 8개(무리당 4~7송이), 잡초 30개**를 배치.
10. **검증 (보장)**: 플레이어 집 문에서 BFS(통행 가능 + 경사로 + 다리). 다음 전부 도달 가능해야 통과:
    모든 부지 문, 3개 높이 레벨 각각 ≥ 200타일, 해변, 각 연못 물가, 강 본류·지류 물가, 바위 6개 전부, 과일나무 전부.
    실패 → ① 도달 불가 영역과 가장 가까운 절벽에 경사로 추가 / 강이면 다리 추가 후 재검사, ② 3회 실패 시 `seed+1`로 재생성(최대 10회, 이후 예비 고정 시드). 생성 시간 목표: 중저가 폰 **< 150ms**.
11. **단위 테스트**: 시드 1~1000에 대해 검증 통과율 100%, 평균/최대 생성시간 기록 (`tools/worldgen-test.html`).

### 1.4 청크 렌더링 & 컬링
- 청크 = **16×16 타일**(256×256 논리 px) → 7×6 = 42청크. 정적 레이어(ground+절벽+물 바탕+해안선)를 청크별 오프스크린 캔버스에 1회 그려 캐시. **LRU 최대 20개**(메모리 ≈ 20 × 256² × 배율² × 4B; 배율 3에서 약 47MB → 배율 3 이상이면 캐시를 논리 해상도로 그리고 `imageSmoothingEnabled=false`로 확대 = 약 5MB).
- 화면에는 보통 3×3~4×3 청크. 카메라 사각형 + 1타일 여유로 컬링.
- 물: 반짝임/물결은 보이는 물 타일에만 4프레임 패턴(250ms 주기) 오버레이. 폭포·파도선은 별도 애니메이션.
- 오브젝트: 보이는 영역의 오브젝트만 수집 → y 정렬(삽입 정렬, 프레임 간 거의 정렬 유지) → 캐시된 스프라이트 drawImage. 계절 변경 시 해당 계절 스프라이트 시트 재생성(1회 ~40ms).
- 지형이 변하는 경우(나무 벌목 X, 로드맵 지형 편집 O)에만 해당 청크 무효화.

### 1.5 충돌·이동
- 플레이어 = **원(반지름 0.3타일)**. 타일 충돌은 축 분리(x 먼저, y 다음) + 모서리 미끄러짐(코너 0.2타일 이내면 수직 방향 보정).
- 오브젝트 충돌: 나무 원(0.4), 바위 원(0.45), 건물 사각형. 꽃·잡초·조개는 통과.
- 절벽: 높이가 다른 타일로는 경사로 플래그가 있을 때만 이동. 물 진입 불가(베타), 로드맵 수영 시 해당 레이어만 허용.
- 속도: **걷기 4.0 타일/s, 달리기 6.5 타일/s**(PC Shift / 모바일 조이스틱 끝까지 75% 이상), **살금 1.6 타일/s**(채집망 들고 버튼 누른 채). 가속 0→최고 120ms, 정지 80ms. 달리기 중 꽃 위 지나가면 20% 확률 꽃잎 파티클(꽃 파괴는 없음 — 서윤 요청).

## 2. 맵 오브젝트와 매일 리스폰

### 2.1 오브젝트 레코드
`{t:type, x, y, s:state(0~255), d:dayStamp(마지막 변화 dayIndex), v:variant}` — 저장 시 6바이트 패킹.

### 2.2 나무
| 종류 | 위치 | 성장 | 채집 |
|---|---|---|---|
| 활엽수 | 레벨0~2 | 묘목→작은→중간→큰→성목, **단계당 1일(총 4일)**. 주변 8칸에 다른 나무/건물 있으면 성장 정지 | 도끼질 1일 3회까지 목재 지급(**목재 ×3/일**: 나무 60%/단단한 나무 25%/가벼운 나무 15%). 흔들기: 가지 30%, 코인 주머니(마을 전체 1일 1회), 벌집 5%(말벌 출현), 가구 1일 1그루 |
| 과일나무(5종 중 마을 특산 1종: 사과·복숭아·배·귤·체리) | 레벨0~1 | 동일 + 성목에 과일 3개 | 과일 수확 후 **3일 뒤 재결실**(d 기준). 비특산 과일은 판매가 ×5(경제팀 확인) |
| 침엽수 | 레벨2 중심 | 동일 | 목재 ×3/일, 겨울(12월) 솔방울 흔들기 드롭 |
| 야자 | 해변 | 동일 | 코코넛 2개, 3일 재결실 |
- 베타에서 나무 **벌목(그루터기화)은 제외**(도끼는 목재 채취만). 묘목/과일 심기는 베타 포함(빈 타일 + 주변 1칸 여유).

### 2.3 바위
- 6개 고정 위치(생성 시). 삽·도끼 아님, **도끼/삽으로 치기** → 1일 최대 **8회** 드롭(연타 0.6s 이내 유지 시 다음 드롭). 드롭: 돌 50%, 점토 25%, 철광석 18%, 금광석 2%, 원석(색 6종 랜덤) 5%.
- 매일 6개 중 1개가 **코인 바위**(시드: world+day): 드롭이 코인 100→200→…(경제팀). 치는 반동으로 플레이어 0.3타일 밀림(뒤에 막힌 공간 있으면 더 많이 침 = 공략 포인트).

### 2.4 꽃·잡초
- 꽃 베타 4종(튤립·코스모스·팬지·장미) × 기본색 3(빨·노·흰). 물주기 X, 교배 X(로드맵). 꽃 무리 근처에 곤충 스폰 가중.
- 잡초: 매일 **+3개**(빈 잔디 타일 무작위), 부재 일수 n이면 +min(3n, 40), 상한 80. 계절 3종 스프라이트(봄 클로버/여름 강아지풀/가을 억새). 뽑으면 "잡초" 재료(제작용).

### 2.5 발굴·해변·계절 아이템 (매일 05:00 생성, 시드 = hash(seed, dayIndex, kind))
| 항목 | 개수/일 | 규칙 |
|---|---|---|
| 화석 지점(별 모양 금) | **4** | 레벨0~2 잔디/흙. 플레이어 집·부지 2타일 밖 |
| 반짝이는 지점 | 1 | 파면 코인. 그 자리에 코인을 묻으면 다음날 나무(로드맵) |
| 묻힌 아이템 | 2 | 점토·원석·"오래된 도자기 조각"(수집품) |
| 조개(해변) | **6~10** | 가리비·바지락·소라·고둥·산호조각(각 15~25%), 진주조개 2% |
| 버섯 | 4 (11월만) | 숲 밀집 나무 밑동 |
| 벚꽃잎 더미 | 3~5 (4/1~4/10) | 바람 부는 날 광장·길 |
| 단풍잎/도토리·솔방울 | 흔들기 드롭 (9~11월 / 12월) | 나무당 1일 1회 |
| 눈송이 굴리기 | 2개 (12~2월 눈 쌓인 날) | 굴리면 커짐 → 쇠똥구리 스폰 연동 |
- 미수집분은 다음날 05:00에 **사라지고 새로 생성**(누적 없음). 단, 화석은 상한 4 유지.

## 3. 시간

### 3.1 실시간 시계
- `G.time.now()` = 기기 로컬 시각(`Date`) + 디버그 오프셋(`G.DEBUG`일 때만 `?t=2026-07-01T20:00` 지원, QA용).
- **dayIndex** = floor((localMs − 5h) / 24h)(로컬 자정 기준 계산, DST 하루 23/25시간은 날짜 문자열로 산출해 오차 제거).
- 틱: 게임 루프에서 1초마다 분 변경 체크 → `time:minute`, `time:hour`, `time:day`(05:00) 이벤트 발행(`G.bus`).
- 앱 백그라운드 복귀(visibilitychange) 시 즉시 재계산 → 날이 바뀌었으면 "새 아침" 페이드 후 리스폰 처리.

### 3.2 시간 여행 처리 (안티치트 라이트)
- 저장: `lastRealMs`, `maxDayIndex`(지금까지 본 최대 날짜), `lastRefreshDay`.
- **앞으로 점프**(dayIndex > lastRefreshDay): 경과 n일 캐치업 — 나무 성장 min(n,4)단계, 과일 재결실, 잡초 +min(3n,40), 일일 오브젝트 재생성은 **오늘 것만** 1회. 7일 이상이면 주민 "오랜만이야" 플래그(주민 AI 팀 연동).
- **뒤로 점프**(dayIndex < maxDayIndex 또는 lastRealMs − 2h 이상 역행): 계절·시간대·생물·날씨는 **현재 시계를 그대로 따름**(겨울 생물 보러 가기 허용). 그러나 리스폰·일일 보상(코인 바위, 흔들기 코인, 화석, 조개, 과일 재결실)은 `dayIndex > lastRefreshDay`일 때만 지급 → 되돌리기로 반복 파밍 불가.
- 기록용 `timeTravelCount` 저장(업적 "시간 방랑자" 정도로만 사용, 처벌 없음). 미르의 패널티 안은 기각, 기록에 남김.

### 3.3 계절
- 월 기반, 설정에서 **북/남반구 토글**(남반구 = 월 +6). 봄 3~5, 여름 6~8, 가을 9~11, 겨울 12~2.
- 세부 시기: 벚꽃 4/1~4/10, 장마 느낌 6/15~7/15(비 확률 ↑), 단풍 11/10~11/30, 적설 12/10~2/24(지면 눈 타일 + 발자국).
- 계절 팔레트: 잔디 기본색 4종 + 전환기 7일간 선형 보간(일 단위).

### 3.4 날씨 생성기 (시드 = hash(seed, dayIndex, 'wx'), 저장 불필요)
- 하루 패턴 14종 중 1개 선택(월별 가중표) → 시간별 날씨 배열 24칸.
  패턴 예: 종일 맑음, 맑음→오후 흐림, 흐림 종일, 오전 비→맑음, 오후 비, 종일 비, 폭풍(뇌우), 소나기 2회, 밤 비, 눈(겨울), 종일 눈, 눈→맑음, 안개 아침(로드맵), 별똥별 밤.
- 월별 가중 예: 1월 맑음 45/흐림 25/눈 30, 4월 맑음 55/흐림 25/비 20, 7월 맑음 45/흐림 15/비 30/폭풍 10, 10월 맑음 60/흐림 25/비 15. 12~2월에는 비→눈 치환.
- **무지개**: 비→맑음 전환이 10~16시에 있으면 50% 확률로 전환 후 1시간 하늘 무지개(전용 곤충 보너스 없음, 사진 이벤트 로드맵).
- **별똥별**: 맑은 밤(19~4) 일반 1~2회 랜덤. 월 1~2일 "유성우 밤"(전 시간 맑음 강제): 19~4시 동안 시간당 3~5회 묶음 발생, 하늘 볼 때 소원 버튼 → 다음날 해변에 "별 조각" 1~3개(로드맵 제작 재료, 베타는 수집품만).
- 바람 세기 0~3 (나뭇잎/꽃 흔들림, 벚꽃잎 더미 생성 조건).

### 4.1 종 데이터 필드
```js
{ id:'bug_tiger_swallowtail', name:'호랑나비', kind:'bug', months:[4,5,6,7,8,9],

  behavior:'flutter', flee:3.0, price:240, desc:'도감 문구(대화팀)' }
// 물고기: shadow:1~6|'fin'|'long', loc:'river'|'riverTop'|'mouth'|'pond'|'sea'|'pier'
// weather: 'any'|'noRain'|'rainOnly'|'clear'  / rarity 1(흔함)~5(전설)
```

### 4.2 스폰 시스템
- 슬롯 방식: 화면 주변(카메라 ±1.5화면) **곤충 최대 8, 물고기 그림자 최대 10**. 3초마다 빈 슬롯 1개 채우기 시도, 화면 밖 30초 경과 개체는 제거.
- 후보 = 현재 월·시·날씨·장소 조건 통과 종. 가중치 = 희귀도 가중(★1 100, ★2 50, ★3 20, ★4 8, ★5 3) × 장소 매칭 계수. 같은 종 동시 최대 2.
- 장소 타입은 타일 flags/오브젝트로 판정: flower(꽃 2타일 내), tree(나무 줄기), shake(흔들기), ground, rock(바위 치기), snowball, beachRock, pond_surface, lamp(가로등·창문 불빛), fruit(떨어진 과일), air(아무 곳).

### 4.3 곤충 행동
- 도망 반경(flee, 타일): 기본값은 종별. **걷기 ×1.0, 달리기 ×2.0, 살금 ×0.5**. 반경 안 진입 시 도망(날벌레는 화면 밖, 지면 벌레는 2~4타일 이동 후 숨기).
- 그물 휘두르기: 0.35s 준비 → 판정 원 반경 0.7타일(중심 1타일 앞). 실패 시 해당 개체 경계 ×1.5.
- 행동 타입: flutter(사인 곡선 비행), dart(직선 돌진+정지), perch(줄기에 붙어 있음, 접근 시 소리), hop(점프), crawl(지면), skate(수면), sting(말벌: 3초 내 못 잡으면 쏘임 → 얼굴 부음 연출, 처벌 없음), fall(흔들기로 떨어짐).

| 키 | 내용 | 형식 | 예상 크기 |

## 11. [개정] 오너 지시 반영 — 종 수 "수백" + 변이(바리에이션) 체제 (4.4·4.6·4.7·5장의 수량을 대체)

> 최종 오너 지시: 수집 규모 **곤충 1,200 / 물고기 1,200 = 기본종 200 × 변이 6종**(일반·거대·알비노·희귀 무늬·황금·계절색), 해산물 80, 화석 100.
> 베타: **기본종 곤충 60 / 물고기 60(변이 시스템 동작) + 해산물 20 + 화석 20**.
> 4.4(26종)·4.6(25종) 표는 아래 표의 1~26 / 1~25번으로 **그대로 포함**되고 번호를 이어 추가한다. 스폰·행동·낚시 규칙(4.1~4.3, 4.5)은 유지.

### 11.1 추가 토론
- 도현: 해산물 20이 베타에 들어오면 **수영·잠수가 베타로 당겨짐**. 1개월차 항목을 베타로 이동(얕은물 레이어 6 + 바다 수영 영역 + 잠수 거품).
- 미르: 60/60이 "어디서나 다 나오는" 느낌이면 안 된다 → 곤충 장소 15유형, 물고기 장소 9유형으로 확장해 공간 분산.
- 서윤: 아트 부담 3배 + 변이 6종. **파라메트릭 생물 생성기**(몸통 템플릿 × 팔레트/무늬 파라미터) 없으면 불가. 변이는 전부 팔레트·무늬·스케일 변환으로만 표현 → 아트A와 베타 전제조건으로 합의.
- 한결: 곶(바위 해안) 2곳·폭포 웅덩이·고지대 연못을 생성 보장 항목(1.3-10)에 추가.
- 미르 vs 도현(변이 확률): 미르는 황금 1/2000 고정(희소성), 도현은 ★5 종은 1년에 10마리도 못 잡으니 고정 확률이면 영원히 불가능 → **희귀도 보정 + 동정(pity) 카운터**로 합의.

### 11.6 변이(바리에이션) 시스템 — 곤충·물고기 공통
**판정 순서**: 스폰 시점에 종 결정 → 변이 1회 판정(우선순위 황금 > 알비노 > 희귀 무늬 > 계절색 > 거대 > 일반, 한 개체 1변이). 변이 개체는 스폰 즉시 외형에 반영(그림자 단계에서도 황금은 반짝임 2px, 알비노는 그림자 옅음 → "보고 쫓는" 손맛).
**희귀도 보정 R** = ★1 1.0 / ★2 1.5 / ★3 2.5 / ★4 5 / ★5 10 (희귀종일수록 변이 확률↑, 잡을 기회가 적기 때문).

| 변이 | 기본 확률 | 조건 배수 | 표현 |
|---|---|---|---|
| 거대 | 3% × R(상한 15%) | 물고기: 비/폭풍 ×2, 곤충: 보름달 밤 ×1.5 | 크기 = 종 평균 × 1.5~2.0, 그림자 +1단계, 도망 반경 ×1.2 |
| 계절색 | 8% (지정 계절 안에서만, 그 외 0) | 지정 계절 마지막 달 ×1.5 | 팔레트 교체(봄 분홍 / 여름 청록 / 가을 적갈 / 겨울 은백) |
| 희귀 무늬 | 1/80 × R | 종별 "무늬 트리거" 충족 시 ×5, 미충족 ×0.5 | 무늬 파라미터 교체(점↔줄↔고리) |
| 알비노 | 1/200 × R | 그믐(신월) 밤 ×3, 폭풍 ×1.5 | 흰 몸 + 붉은 눈 팔레트 |
| 황금 | 1/1000 × R | 보름달 밤 ×2, 유성우 밤 ×4, 무지개 시간 ×3 (중복 시 최댓값만) | 금속 그라디언트 + 반짝 파티클 |

- **계절색 지정**: 종이 출현하는 계절이 2개 이상이면 "주 계절이 아닌 쪽" 1개를 지정. 한 계절만 나오는 종은 출현 창의 마지막 2주에만 15%.
- **무늬 트리거 8종**(종마다 1개 배정, 데이터 필드 `patTrig`): 무지개 시간, 눈 오는 중, 폭포 웅덩이, 특정 꽃색 2타일 내(빨/노/흰), 비 그친 직후 1시간, 새벽 4~6시, 유성우 밤, 바람 세기 3.
- **달 위상**: 실제 날짜로 계산(삭망월 29.530588일, 기준 신월 2000-01-06 18:14 UTC). 보름 = 위상 0.47~0.53, 그믐 = 0.97~0.03, 밤 19~4시만 적용. HUD에 달 아이콘 표시(조건이 "보이게").
- **동정(pity)**: 종별 카운터 `pc[speciesId]`가 해당 종 포획마다 +1. 황금은 pc ≥ 300부터 1포획당 확률 +0.1%p, 알비노는 pc ≥ 120부터 +0.2%p. 해당 변이 획득 시 0으로. (★5 종은 R=10으로 이미 1/100이라 거의 발동 안 함.)
- **크기 분포**: 모든 개체 크기 = 종 평균 × 로그정규(σ=0.12), 거대 변이는 [1.5, 2.0] 균등. 도감에 종별 최대 크기 기록 → 변이 외의 무한 목표(최대 기록 갱신, 마을 게시판 랭킹은 로드맵).
- **수집 단위**: 도감 1종 = 6칸(일반·거대·알비노·희귀 무늬·황금·계절색). 베타 수집 칸 = 60×6 + 60×6 + 20×2 + 20 = **780칸**. 완성판 = 1,200 + 1,200 + 240 + 100 = **2,740칸**.
- **저장**: 종별 6비트 변이 플래그 + 최대크기(1B) + pc(2B) → 400종 × 4B ≈ 1.6KB(base64 ~2.2KB). 시스템팀 도감 저장소와 공유.

### 11.7 완성판 200/200/80 분포 설계 — "6개월 넘게 도감이 안 끝나는" 규칙
**(a) 기본종 배분 목표 (곤충·물고기 각 200)**
| 축 | 배분 |
|---|---|
| 월 창 | 연중 15% / 6~9개월 25% / 3~5개월 35% / 1~2개월 한정 25% → 각 달에 그 달 한정 종 ≥ 4, 매달 "첫 등장" 10~16종 / "이달로 끝" 10~16종 |
| 시간대 | 전일 40% / 낮(8-17) 22% / 새벽(4-8)·저녁(16-19) 10% / 밤(19-4) 20% / 2~4시간 좁은 창 8% |
| 날씨 | any 65% / noRain 15% / rainOnly 8% / clear 6% / snow 3% / storm 1.5% / 무지개·유성우 한정 1.5% |
| 서식지 | 곤충 22유형(고산·동굴·눈밭·낙도 열대·특정 꽃색·특정 나무종 추가), 물고기 14유형(부두·낚싯배 심해·낙도·폭포 상/하단), 해산물 수심 3단(깊음은 장비 해금) |
| 희귀도 | ★1 28% / ★2 30% / ★3 22% / ★4 13% / ★5 7%. ★5는 해당 시기 1시간 플레이 기대 조우 0.15~0.3회 |
| 해금 조건 | 10%는 진행 조건(꽃 교배색, 고지대·낙도·부두 개방, 이벤트 주간) |
**(b) 출시 곡선 (곤충/물고기/해산물/화석)**: 베타 60/60/20/20 → 1개월 85/85/30/35 → 2개월 110/110/40/50 → 3개월 135/135/50/65 → 4개월 160/160/60/75 → 5개월 180/180/70/90 → 6개월 **200/200/80/100**. 추가 종은 출시 월과 무관하게 **연간 달력 전체에 분포** → 6개월차 추가분 일부는 이미 지난 계절이라 최소 1년 필요(의도).
**(c) 매일 할 것 보장**: 어느 날·어느 시간이든 ① 그 달 신규 등장 종 ≥ 3, ② 미수집 ★1~2 기본종 ≥ 2, ③ 오늘 조건이 맞는 변이 기회(달 위상·날씨·트리거) ≥ 1개를 HUD "오늘의 기운"으로 안내.
**(d) 검증 `tools/eco-sim.js`**: 가상 플레이어 3유형(아침 20분 / 저녁 40분 / 주말 낮 90분 추가), 180일·365일 몬테카를로 1,000회. 합격 기준(완성판 데이터):
- 기본종: 180일 달성률 중앙값 70~82%, 상위 5% ≤ 92%; 30일 ≥ 25%. 하루 평균 신규 기본종 ≥ 1(180일까지).
- 변이 칸(1,200): 180일 중앙값 **20~30%**, 365일 중앙값 40~55%, 황금 180일 ≤ 10%. 변이 칸 신규 획득이 하루 ≥ 1.5칸(365일까지 유지).
- 월별 출현 기본종 하한: 곤충·물고기 각 매달 ≥ 70종(완성판), 베타 ≥ 22종.
**(e) 성능**: `time:hour`·`weather:change`·달 위상 변경 시에만 (장소유형 → 후보 배열, 변이 배수 테이블) 인덱스 재계산(200종 × 36유형 ≈ 0.1ms). 변이 판정은 스폰 1회당 난수 1개.
