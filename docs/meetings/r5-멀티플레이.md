# 5차 회의 — 멀티플레이 1차 (친구 마을 놀러 가기 + 채팅)

오너 요청: "같은 맵을 공유하고 마을에서 만나서 직접 물건도 주고", "채팅을 할 수 있어야", "친구 추가 누르면 가입한 사람 목록을 보여 줘서 쉽게 고르게".

## 결정
- 방식: 각자 자기 마을이 있다. 친구가 「내 마을 열기」를 하면 놀러 갈 수 있다(동물의 숲 방식). 주인이 접속해 있어야 한다.
- 친구 찾기: 잎첩 「👫 친구」 탭.
  - 가입한 사람 목록(최근 60명, 마을 문 연 사람 먼저)에서 「＋ 친구」·「놀러 가기」.
  - 친구 코드 6자리로도 찾을 수 있다.
- 보이는 정보: 캐릭터 이름·마을 이름·모습뿐. 아이디·이메일은 어디에도 올리지 않는다.
- 같이 놀기
  - 서로의 캐릭터가 실시간으로 보인다(초당 4번, 움직일 때만 전송).
  - 💬 채팅: 말풍선 + 화면 왼쪽 기록. 빠른 감정 8개. 60자, 1.2초 간격, 욕설은 ♡로 가린다.
  - 🎁 선물: 친구 앞에서 행동 버튼 → 가방에서 하나 골라 보낸다.
- 손님 규칙
  - 친구 마을에서는 벌레·물고기·조개·바다생물만 잡는다. 잡은 건 내 가방에 들어간다.
  - 나무·땅·바위·건물·텃밭·목장은 주인 것이라 「구경」만 한다.
- 안전
  - 손님일 땐 내 세이브를 멈추고 내 마을 상태를 따로 보관한다. 돌아오거나 창을 닫으면 복원 후 저장한다.
  - 주인은 손님을 내보낼 수 있다.
- 서버: Firebase RTDB.
  - 경로: codes · directory · rooms/{주인}/{info, players, chat, gifts, kick}.
  - 규칙은 firebase.database.rules.json에 있다.
  - 무료(Spark) 한도 안: 동시 접속 100, 10명이 놀아도 시간당 수백 MB 이하.
