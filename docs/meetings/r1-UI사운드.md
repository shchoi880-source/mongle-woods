# 1차 회의 제안서 — UI·QA 팀 + 사운드 팀 (합동)

- 참석: **윤다온**(UI 구현), **강태리**(QA 검토) / **민소리**(사운드 구현), **오해준**(사운드 검토)
- 범위: 조작·화면·HUD·메뉴, 연출(juice)·접근성, 세이브 UX, 오디오 전체, 자동 검증·성능 예산, PWA, 모듈 API
- 표기: 【쟁점】= 멤버 간 의견 충돌, 【합의】= 최종안. 화폐명은 시스템·경제팀 확정 전까지 "코인(가칭)".

## 0. 요약 (총괄용 10줄)
1. **세로(portrait) 고정**, 논리 해상도 월드 **180×320**(16px 타일) / UI **360×640**, 정수배 스케일 + 안전영역 반영.
2. 모바일: **플로팅 가상 조이스틱(좌하) + 컨텍스트 액션 버튼(우하)**. 탭 이동은 베타에서 "탭한 칸으로 자동 걷기" 보조 옵션.
3. PC: WASD/방향키, E/Space=액션, 1~8=도구, Tab/I=수첩, 마우스 클릭 이동은 보조.
4. 메뉴 기기 = **"잎사귀 수첩(잎첩)"** — 넘기는 종이 수첩. 앱 7개: 가방·도감·레시피·지도·주민·설정·세이브.
5. Juice: 글자별 타이핑 + 음성 블립, 획득 팝업, 포획 팡파르(2단), 원형 와이프 전환, 버튼 눌림 2px+사운드+진동.
6. 세이브: 이벤트+60초 자동저장, **A/B 이중 슬롯 + FNV-1a 체크섬**, schemaVersion 순차 마이그레이션, 파일/문자열 내보내기.
7. BGM: **"기본 진행 4종(새벽/낮/저녁/밤) × 시간별 변주 파라미터 24행"** 테이블. 비=저역통과+빗소리 레이어, 계절=스케일·악기 색.
8. 주민 목소리 = 대사 글자 → 음절 해시 → 포먼트 2개 필터 블립. iOS 오디오 언락은 첫 터치에서.
9. `tools/verify.js`(Node, 의존성 0): 참조 무결성, 180일 경제 시뮬, 스폰표 12×24 커버리지, 세이브 왕복, 맵 BFS 도달성.
10. PWA: `VERSION` 상수 1개로 캐시명 결정, 새 버전 감지 시 "새 버전 — 탭하여 갱신" 토스트(강제 리로드 금지).

## 1. 조작 (Controls)

### 1.1 화면 방향 【쟁점】
- **윤다온(UI)**: 가로. 마을 시야가 넓고 PC와 화면비가 같아 레이아웃 1벌로 끝난다.
- **강태리(QA)**: 세로. 코지게임은 "한 손, 누워서, 출퇴근 지하철" 플레이가 핵심 사용 패턴. 가로는 양손 필수.
  또 중저가 폰에서 가로는 캔버스 픽셀이 더 많아(주소창 숨김 시) 필레이트 부담 증가.
- **오해준(사운드 검토)**: 방향은 오디오와 무관하나, 세로면 스피커가 손에 가려지는 문제가 덜하다(하단 스피커 기기).
- 【합의】**세로 고정이 기본**. PC는 세로 캔버스를 중앙에 두고 좌우 여백에 장식 테두리(나무결 패턴, 코드 드로잉).
  가로 회전 시: 게임 정지 X, 레터박스로 같은 세로 화면 유지 + "세로로 돌려주세요" 아이콘 1초 표시 후 사라짐.
  6개월 로드맵에 "PC 와이드 모드(시야 확장)" 검토 항목으로 남긴다.

### 1.2 논리 해상도·스케일
| 항목 | 값 |
|---|---|
| 타일 크기(논리) | 16px |
| 논리 해상도 | **180×320** (월드 렌더), UI 레이어는 **360×640** (UI는 2배 정밀) |
| 화면 내 타일 | 가로 11.25, 세로 20 → 카메라는 플레이어 중심, 위쪽 여백 약간 더 보이게(+1타일 오프셋) |
| 스케일 | `floor(min(vw/180, vh/320))` 정수배, 남는 공간은 배경색. devicePixelRatio 반영 후 `imageSmoothingEnabled=false` |
| 안전영역 | CSS `env(safe-area-inset-*)`를 JS에서 읽어 `G.ui.safe = {t,r,b,l}`(논리 px)로 보관. HUD·버튼은 이 값만큼 안쪽 |
| 최소 지원 | 360×640 CSS px (갤럭시 A 시리즈 기준), 아이폰 SE 2세대 |

- 강태리 반론: 정수배만 쓰면 일부 기기에서 위아래 여백이 20%까지 생긴다 → 합의: 월드는 정수배, 남는 세로 공간은 **월드 시야 확장**(행 수 늘림)으로 채운다. 여백 0.

### 1.3 모바일 이동 【쟁점】
- 윤다온: **탭 이동(탭한 곳으로 A* 걷기)**. 화면을 가리는 UI가 없고 귀엽다.
- 강태리: 탭 이동은 곤충 몰래 접근(느린 걸음), 물고기 그림자 앞 정밀 위치, 가구 배치에서 실패. 실측상 탭 이동 게임의 1위 불만이 "원치 않는 오브젝트를 탭해서 상호작용".
- 【합의】
  - 기본: **플로팅 조이스틱** — 화면 왼쪽 55% 영역 아무 곳이나 터치한 지점이 중심. 반지름 36 UI-px, 데드존 6px.
    - 기울기 0~50% = **살금살금 걷기**(곤충용, 속도 40%), 50~100% = 걷기, 끝까지 1초 유지 = 달리기(속도 170%).
    - 손을 떼면 즉시 정지(관성 없음 — 정밀 위치가 우선).
  - 옵션(설정에서 켜기): **탭-투-무브** — 지면 탭 시 해당 칸까지 경로 이동, 오브젝트 탭 시 인접 칸까지 걸어가 자동 액션.
  - 8방향 이동, 대각선은 정규화. 충돌은 타일 단위가 아닌 히트박스(10×6px 발밑) 기준.

### 1.4 액션 버튼 컨텍스트 규칙
- 우하단 **원형 액션 버튼 1개(지름 64 UI-px)** + 그 위 작은 **도구 버튼(지름 44)**.
- 액션 버튼 아이콘은 매 프레임 "바라보는 방향 1칸 + 발밑"의 대상에 따라 바뀜. **우선순위 표(위가 우선)**:

| 순위 | 조건 | 표시 아이콘 | 동작 |
|---|---|---|---|
| 1 | 대화 중 | ▶ | 다음 대사 / 타이핑 스킵 |
| 2 | 주민 인접 | 말풍선 | 대화 |
| 3 | 떨어진 아이템 | 손 | 줍기 |
| 4 | 표지판·우편함·문·가구 | 눈/문 | 읽기/들어가기/앉기 |
| 5 | 장착 도구가 대상에 유효(잠자리채+벌레, 낚싯대+물, 삽+땅/X표, 도끼+나무) | 도구 아이콘 | 도구 사용 |
| 6 | 나무(도구 없음) | 흔들기 | 나무 흔들기 |
| 7 | 그 외 + 도구 장착 | 도구 아이콘(반투명) | 허공 스윙 |
| 8 | 그 외 | 흐린 점 | 아무것도 안 함(버튼은 눌림 피드백만) |

- 길게 누르기(0.4초): 낚시 중 = 릴 감기 유지 대신 사용 안 함(낚시는 "입질 때 탭" 1회 판정). 삽 = 묻기/메우기 전환 메뉴.
- 액션 버튼 위에 대상 이름을 작은 라벨로 0.6초 표시(예: "참나무", "소금쟁이") — 오조작 감소.

### 1.5 도구 전환
- 도구 버튼 탭 → **원형(링) 선택 메뉴** 펼침, 최대 8칸. 손가락을 떼지 않고 밀어서 선택(드래그 릴리즈), 또는 탭 선택.
- 도구 버튼 **좌우 스와이프** = 이전/다음 도구 빠른 순환(QA 요청: 한 손 엄지로 0.3초 안에 교체).
- 도구는 가방 슬롯을 차지하는 아이템이되, 링 메뉴는 "가방 속 도구 + 빈손"만 자동 수집.

### 1.6 PC 입력
- WASD/방향키 = 이동(Shift 달리기, Ctrl/Alt 살금) · E/Space = 액션(1.4 우선순위 동일) · 1~8 = 도구 직접 선택, 0 = 빈손, Q/R = 이전/다음
- Tab/I = 잎첩 열기/닫기(안에서 ←→ = 앱 탭) · Esc = 닫기/뒤로(최상위에선 설정)
- 마우스 좌클릭 = UI 조작, 월드에선 클릭 이동(PC는 기본 on) · 휠 = 가방 페이지, 인테리어 모드 가구 회전
- 키 리매핑은 6개월 로드맵. 게임패드(Gamepad API)도 로드맵(베타는 감지 시 "지원 예정" 표시만).

## 2. HUD와 메뉴 시스템

### 2.1 HUD 레이아웃 (세로, UI 360×640 기준, 안전영역 안쪽)
```
┌───────────────────────────────────────┐
│(날씨)[오후 3:42 · 11월 23일(월)]  [● 1,240]│ ← 좌상 시계 리본 h28(날씨는 왼쪽 원 아이콘) / 우상 코인
│        [토스트 영역: 중앙 상단 y=90]        │
│                 (월드)          [잎첩 44]│ ← 우측 중단
│ (조이스틱 영역: 좌측 55%)  [도구 44][액션 64]│ ← 우하단
└───────────────────────────────────────┘
```
- 코인은 변동 시에만 1.5초 확대 표시 후 축소.
- **최소주의 원칙(합의)**: 3초간 입력 없으면 시계·코인 리본이 반투명(α0.6). 이동 중엔 숨기지 않음(시간 확인이 게임의 핵심).
- 현재 도구는 도구 버튼 안 아이콘 + 내구도 바(로드맵: 도구 내구도는 시스템팀 결정 대기).
- 시간 표시 형식: "오후 3:42". 24시간제 옵션은 설정.

### 2.2 잎사귀 수첩 ("잎첩") — 오리지널 메뉴 기기 콘셉트
- 설정: 마을에 이사 오면 이장이 건네는 **큰 잎사귀를 엮어 만든 수첩**. 책갈피 끈 7개 = 앱 7개.
- 연출: 열면 화면 하단에서 수첩이 올라오며(220ms, ease-out-back) 표지가 넘어감. 각 앱 = **색깔 책갈피 탭**(왼쪽 세로).
  닫을 때 "탁" 덮는 소리. 수첩 열려 있어도 **게임 시간은 흐름**(실시간 게임이므로), 단 플레이어 위협 요소 없음(벌 제외 — 벌 추격 중엔 수첩 열기 불가).
- 레이아웃: 수첩 크기 340×560, 왼쪽 책갈피 열(48px) + 오른쪽 페이지.

| 책갈피 | 앱 | 베타 기능 |
|---|---|---|
| 연두 | **가방** | 그리드, 팔기 예약, 버리기, 정렬 |
| 하늘 | **도감** | 곤충/물고기/화석 탭, 이번 달 출현 필터, 미발견은 실루엣 |
| 주황 | **레시피** | 보유 레시피, 재료 보유 수 표시, 제작대 근처에서만 "만들기" 활성 |
| 갈색 | **지도** | 마을 전체 미니어처, 내 위치, 주민 집, 상점 영업 시간 |
| 분홍 | **주민** | 주민 카드(이름·생일·좋아하는 것·친밀도 하트 5단계) |
| 회색 | **설정** | 음량 3종, 글자 크기, 모션 줄이기, 색약 모드, 조작 방식, 진동 |
| 노랑 | **세이브** | 수동 저장, 내보내기/가져오기, 마지막 저장 시각 |

### 2.3 가방(인벤토리) 터치 UX 【쟁점】
- 윤다온: 드래그 앤 드롭으로 칸 정리 + 휴지통/판매함으로 끌어놓기.
- 강태리: 드래그는 작은 화면에서 스크롤과 충돌하고 오발이 잦다. 팔기는 "여러 개 선택 → 한 번에"가 필수(곤충 20마리 판매 반복 노동 방지).
- 【합의】
  - 그리드 5열×4행 = 20칸(베타 시작 용량, 확장은 경제팀). 칸 크기 56px(터치 타겟 ≥ 44px 준수).
  - **탭** = 아이템 상세 + 행동 시트(하단): [들기/장착] [놓기] [먹기] [선물] [버리기].
  - **길게 누르기 0.3초 → 들어올림** → 드래그로 칸 이동/교환(들어올린 뒤에만 드래그 → 스크롤 오발 방지).
  - **빠른 버리기**: 들어올린 상태로 가방 밖(월드 쪽 반투명 영역)에 놓으면 발밑에 떨굼.
  - **판매(상점에서만)**: 판매 모드 진입 시 탭 = 선택 토글(초록 체크), 같은 종 자동 묶음 "같은 것 모두" 버튼, 하단에 합계 실시간 표시, [팔기] 1회 확인.
  - 정렬 버튼: 종류 → 가격 → 이름. 겹치기(스택) 최대치는 데이터의 `stack` 값(기본 10, 생물은 1).
  - 가방 가득 찼을 때: 획득 시 "가방이 가득 찼어요" + [버리고 넣기]/[그대로 두기] 2지선다, 그대로 두면 발밑에 떨굼.

## 3. 손맛(Juice)·접근성

### 3.1 대화창
- 하단 말풍선형(높이 140, 둥근 모서리 18, 화자 이름표 좌상단 돌출). 글자 출력 **기본 35자/초**, 문장부호(, . ! ?) 뒤 120~250ms 정지.
- 글자 2개마다 음성 블립 1회(5.2 참조). 공백·문장부호엔 블립 없음.
- 탭: 출력 중 → 즉시 전체 표시, 완료 → 다음. 완료 시 ▼ 커서가 2Hz로 통통 튐.
- 감정 태그(`{기쁨}`, `{놀람}`)는 대화팀 데이터 → 블립 피치 +3반음 / 글자 크기 1.2배 흔들림 등 표현으로 매핑.

### 3.2 획득·포획 연출
| 이벤트 | 시각 | 소리 | 진동 | 길이 |
|---|---|---|---|---|
| 아이템 줍기 | 머리 위 아이콘 팝(스케일 0→1.2→1, 400ms) + 우측 토스트 "참나무 가지 +1" | 짧은 "뽁"(C6) | 10ms | 0.6s |
| 포획(평범) | 캐릭터가 머리 위로 들어올림 + 반짝 파티클 8개 + 대사창 1줄 | 3음 상행 팡파르 | 30ms | 1.2s |
| 포획(희귀, 가격 상위 10%) | 위 + 배경 0.3초 암전·스포트라이트 + 별 파티클 16 + "도감 신규!" 도장 | 5음 팡파르 + 종소리 | 30-60-30ms | 2.2s |
| 도감 신규 등록 | 도장 "쾅"(스케일 1.6→1, 화면 흔들림 2px 120ms) | 저음 스탬프 | 40ms | 0.5s |
| 코인 증감 | 코인 리본 숫자 롤링(최대 0.8초) | 동전 짤랑(액수 비례 1~3회) | 없음 | — |
- 연타 방지: 같은 토스트는 합쳐서 "+3"으로 갱신(QA 요구).

### 3.3 화면 전환·버튼 피드백
- 실내외 이동: **원형 와이프**(플레이어 중심 원이 닫힘 250ms → 로드 → 열림 250ms). 모션 줄이기 시 페이드 200ms.
- 수첩 앱 전환: 페이지 넘김(150ms 스큐 + 그림자). 모션 줄이기 시 즉시 교체.
- 모든 버튼: 눌림 시 아래로 2px + 그림자 축소, 뗄 때 스케일 1.05 바운스 80ms, UI 클릭음, 진동 8ms.
- 진동: `navigator.vibrate` 지원 기기만(iOS Safari 미지원 → 무시). 설정에서 끄기 가능, 기본 on.

### 3.4 접근성 (베타 포함)
- **글자 크기 3단계**: 작게 12 / 보통 14 / 크게 17 UI-px. 대화창 높이는 줄 수에 맞춰 자동.
- **모션 줄이기**: 화면 흔들림 0, 전환 = 페이드, 파티클 수 1/4, 조이스틱 시각 효과 최소. `prefers-reduced-motion` 감지 시 기본 on.
- **색약 안전**: 상태 표시를 색 단독으로 쓰지 않는다(판매 선택 = 체크 아이콘+색, 희귀도 = 별 개수+색). 팔레트는 아트팀과 합의 필요하나, UI 의미색 4종은 청록/주황/자주/노랑 계열(적록 구분 회피).
- 대비: 본문 텍스트 대비 ≥ 4.5:1(수첩 종이색 #F6EFD9 위 #4A3B2A = 약 9:1).
- 자막: 모든 의미 있는 효과음(벌 날갯짓, 입질, 비 시작)에 화면 아이콘 동반 — 무음 플레이 보장.
- 타이밍 완화: 낚시 입질 반응창 기본 450ms, 설정 "넉넉하게" 시 700ms.

## 4. 세이브 시스템 UX

### 4.1 자동 저장 타이밍
- 이벤트 저장(즉시, 디바운스 1.5초): 판매/구매, 포획, 도감 등록, 가구 배치 확정, 대화 종료, 실내외 이동.
- 주기 저장: 60초마다 "변경 플래그(dirty)"가 있을 때만.
- `visibilitychange(hidden)`, `pagehide`에서 동기 저장(모바일에서 앱 전환 대비 — 가장 중요).
- 저장 중 표시: 우상단 작은 잎사귀 회전 아이콘 0.8초(저장 실패 시 빨강 아님 → 주황 느낌표 + 토스트).

### 4.2 이중 슬롯 + 체크섬
```js
// localStorage 키
'cozy.save.A' / 'cozy.save.B'   // 번갈아 기록
'cozy.save.meta'                // {last:'A', seq:1042}
// 각 슬롯 내용
{ v: 3, seq: 1042, t: 1763870000000, sum: 'a1b2c3d4', data: {...} }
```
- 쓰기 순서: 직렬화 → `sum = fnv1a32(JSON.stringify(data))` → 이전에 안 쓴 슬롯에 기록 → 다시 읽어 체크섬 검증 → meta 갱신.
- 로드: 두 슬롯 모두 파싱·검증 → 유효한 것 중 `seq` 큰 쪽. 둘 다 실패 → "세이브 복구" 화면(가져오기 유도, 새로 시작은 2단계 확인).
- 용량: 저장 데이터 목표 **≤ 300KB/슬롯**(2슬롯 + 백업 여유로 5MB 안쪽). 초과 경고 임계 1MB. 맵 타일 변경은 RLE 압축 문자열.
- `QuotaExceededError` 시: 다른 슬롯 덮어쓰기 금지, 사용자에게 내보내기 권유.

### 4.3 버전 + 마이그레이션
- `G.save.SCHEMA = 3` 형태 정수. `migrations = {1: d=>..., 2: d=>...}` — **n → n+1 순차 함수만**, 건너뛰기 금지.
- 각 마이그레이션은 순수 함수, 실행 전 원본을 `'cozy.save.premig'`에 1회 백업(다음 정상 저장 후 삭제).
- 규칙: 필드 삭제 금지(사용 중단만), 아이템 ID 변경 시 `idAlias` 표 유지, 알 수 없는 아이템 ID는 "잃어버린 물건 상자"로 이동(삭제 X).
- 미래 버전 세이브(v > SCHEMA, 예: 구버전 캐시로 열림) → 읽기 전용 경고 + 새로고침 유도, **절대 덮어쓰지 않음**.

### 4.4 내보내기/가져오기
- 파일: `마을이름_2026-11-23.cozysave`(내용 = 아래 문자열). `Blob` + `<a download>`; iOS는 공유 시트(`navigator.share` files 지원 시) 폴백.
- 문자열: `COZY1:` + base64(deflate 없음 — 의존성 0 원칙, 대신 JSON 키 축약) + `:` + 체크섬. [복사] 버튼 → 클립보드.
- 가져오기: 파일 선택 또는 붙여넣기 → 검증 → 요약 미리보기("마을 '도토리골', 플레이 42일, 1,240코인, 도감 37/160") → [덮어쓰기] 확인 2단계, 덮어쓰기 전 현재 세이브 자동 내보내기 파일 제안.
- 【쟁점】강태리: 압축(LZ-string 직접 구현) 넣어 문자열 길이 1/3로. 윤다온: 베타는 비압축, 크기 문제 생기면 도입. → 【합의】베타 비압축, `COZY1`/`COZY2` 접두로 포맷 버전 분리해 나중에 압축 추가 가능하게.

## 5. 오디오 (WebAudio 절차적)

### 5.1 BGM 구조 【쟁점】
- 민소리(구현): 시간대 4개 곡 + 날씨 2변형 = 8곡이면 충분, 퀄리티에 집중.
- 오해준(검토): "매 정시마다 바뀌는 음악"이 실시간 코지게임의 정체성. 4곡이면 하루에 3번만 바뀌어 체감 안 됨.
- 【합의】**"진행 4종 × 시간별 변주표 24행"** — 곡은 4개 작곡, 매 시간은 파라미터로 다른 곡처럼 들리게.
  - 진행(Progression) 4종(각 8마디 A + 8마디 B, 루프): 새벽(4~8시)·낮(9~16)·저녁(17~20)·밤(21~3).
  - 시간별 변주표 `data/bgmHours.js`:
```js
// hour: [진행, 키(반음 이동), BPM, 리드 악기, 반주 패턴, 드럼 밀도 0~3, 필터 밝기 0~1]
 6: ['dawn',  +0, 72, 'flute', 'arp8',  0, 0.55],
 7: ['dawn',  +2, 80, 'bell',  'arp8',  1, 0.65],
12: ['day',   +5, 104,'marimba','bounce',3, 1.00],
22: ['night', -3, 66, 'pad',   'sparse',0, 0.35],
```
  - 악기 = 오실레이터 조합 프리셋 8종(flute: 사인+약한 비브라토, marimba: 삼각파+빠른 감쇠, bell: FM 2op, pluck: 노이즈 버스트 카플러스-스트롱 간이, pad: 톱니 2개 디튠+저역통과 등).
  - 멜로디는 진행의 화음 위에서 **시드 고정 생성**(seed = 날짜+시간) → 같은 시간엔 같은 멜로디, 날마다 미세하게 다름. 베타는 수작업 멜로디 4개 + 생성 변주 비율 30%.
  - 정시 전환: 현재 마디 끝에서 2마디 크로스페이드(약 4~6초). 대화·상점 실내는 별도 테마 2종(상점, 집).
- 계절 색:
| 계절 | 스케일 | 추가 레이어 |
|---|---|---|
| 봄 | 메이저 펜타토닉 | 새소리 칩(고음 처프) |
| 여름 | 믹솔리디안 | 매미 노이즈(낮 10~17시, 볼륨 낮게) |
| 가을 | 도리안 | 낙엽 바스락 랜덤 |
| 겨울 | 메이저 + 9th 색채 | 벨 리드 비율↑, 리버브 ↑ |

### 5.2 날씨·환경음
- 비: 화이트노이즈 → 밴드패스(1.2kHz) 빗줄기 + 로우패스 노이즈(바닥 웅웅) + 랜덤 물방울(사인 핑 200ms). **BGM 마스터에 로우패스 2.5kHz**, BGM 볼륨 −4dB.
- 눈: 무음에 가까운 바람(저역 노이즈 아주 작게) + BGM 리버브 증가.
- 바닷가/강가 근처: 거리 기반 파도/물 흐름 노이즈(맵 데이터의 물 타일까지 거리로 볼륨).
- 실내: BGM 로우패스 1.5kHz + 실내 테마로 교체.

### 5.3 효과음 목록 (베타 전부 절차 합성, `data/sfx.js` 파라미터 테이블)
| 분류 | 효과음 | 합성 방식 요약 |
|---|---|---|
| 발소리 | 풀, 흙, 모래, 나무바닥, 돌길, 눈 (6종) | 노이즈 버스트 25~60ms, 지형별 필터 주파수·감쇠 다름, 좌우발 피치 ±3% |
| 도구 | 잠자리채 휘두름, 낚싯대 던지기, 찌 착수(첨벙), 입질(톡톡 2회), 릴/포획, 삽 파기, 구멍 메우기, 도끼 찍기, 나무 흔들기 | 노이즈 스윕 / 사인 피치드롭 / 노이즈+저역 쿵 |
| 획득 | 줍기 뽁, 포획 팡파르(일반/희귀), 도감 스탬프, 화석 발견 | 3·5음 아르페지오, 저음 스탬프 |
| 경제 | 코인 1회/연속, 판매 계산대 땡 | 고음 사인 2개 비트 |
| UI | 클릭, 뒤로, 수첩 열기(종이), 닫기(탁), 페이지 넘김, 오류(부드러운 두 음 하행) | 짧은 사인/노이즈 |
| 생물 | 벌 윙윙(추격 루프), 매미, 새 처프, 개구리(비 오는 밤) | 톱니파 AM / FM |
- 동시 발음 제한: 효과음 보이스 최대 12, 같은 효과음 50ms 내 중복 재생 무시.

### 5.4 주민 목소리 "옹알이" 합성
- 대사 문자열의 **한글 음절을 초성·중성 분해** → 중성(모음)별 포먼트 2개(F1/F2) 표 사용(ㅏ: 800/1200Hz, ㅣ: 300/2300 등 7모음군).
- 각 주민 `voice: {base: 220~520Hz, speed: 0.8~1.3, wave:'square'|'triangle', breathy:0~1}`(주민 데이터에 포함 — 주민AI/대화팀에 요청).
- 블립 = 오실레이터(base × 초성별 미세 피치) → 밴드패스 2개(F1,F2) 병렬 → 엔벨로프 45ms. 물음표로 끝나는 문장은 마지막 블립 피치 +4반음.
- 플레이어 대사는 블립 없음(설정에서 켜기 가능).

### 5.5 iOS 오디오 언락 및 믹서
- 첫 `pointerdown`/`keydown`에서 `AudioContext.resume()` + 1샘플 무음 버퍼 재생. 타이틀 화면 "탭하여 시작"이 그 역할.
- `visibilitychange` 시 suspend/resume, iOS 무음 스위치는 제어 불가 → 설정에 안내 문구.
- 버스: master → {bgm, sfx, voice, amb} 각 GainNode. 설정 음량 3종(배경음악/효과음/목소리, 환경음은 배경음악에 종속).
- CPU 예산: 오디오 노드 동시 생성 ≤ 60, BGM 스케줄러는 `setTimeout` 25ms 룩어헤드 100ms 방식.

- [ ] 안드로이드 크롬 / iOS 사파리 / PC 크롬·엣지·파이어폭스: 첫 실행·홈 화면 추가·오프라인 재실행, 노치 기기 버튼 가림 없음

## 7. PWA
- `sw.js` 첫 줄 `const VERSION = '0.1.0-b3';` → 캐시명 `cozy-${VERSION}`. **`index.html`의 `G.VERSION`과 동일해야 함**(verify.js V11로 검사 추가).
- 전략: 설치 시 앱 셸 전체(html/js/manifest/아이콘) 사전 캐시 → 요청은 **캐시 우선**, 실패 시 네트워크. 활성화 시 이전 버전 캐시 삭제.
- 업데이트: 새 SW가 `waiting`이면 게임이 "새 버전이 있어요 · 탭하여 갱신" 토스트 → 탭 시 **먼저 저장** → `postMessage('skipWaiting')` → `controllerchange`에서 1회 리로드. 대화·포획 연출 중엔 토스트 보류.
- 파일 목록은 `sw.js` 안 배열로 수동 관리, verify.js V12가 `js/` 폴더 실제 파일과 대조.
- `manifest.webmanifest`: `display: standalone`, `orientation: portrait`, `start_url: './'`, `scope: './'`, 배경·테마색 = 수첩 종이색.
- 아이콘: 외부 에셋 금지 → **`tools/make-icons.html`**(브라우저에서 열면 코드로 그린 잎사귀+집 아이콘을 192/512/maskable 512 PNG로 저장)로 생성해 커밋. 런타임 생성은 manifest가 지원하지 않으므로 이 방식.

### 8.1 파일

- `tools/verify.js`, `tools/make-icons.html`, `sw.js`, `manifest.webmanifest`

### 8.2 API 초안
```js
G.input.on('action'|'tool'|'menu'|'back', fn); G.input.move  // {x,y,mag} -1..1
G.scene.push('notebook', {app:'bag'}); G.scene.pop(); G.scene.replace('interior', {house:'shop'})
// 씬 객체: {enter(args), exit(), update(dt), draw(ctx), blocksWorld:true|false}
G.ui.toast(text, {icon, merge:key}); G.ui.itemGet(itemId, n); G.ui.confirm(msg) → Promise<bool>
G.ui.registerApp({id:'dex', tab:'도감', color:'#9fd3e6', draw, update, onTap})
G.fx.shake(px, ms); G.fx.burst(x, y, kind, n); G.fx.transition('circle'|'fade', cb)
G.audio.sfx('step_grass', {pan, vol}); G.audio.voice(text, voiceParams, emotion)
G.audio.setHour(h); G.audio.setWeather('rain'|'snow'|'clear'); G.audio.setScene('indoor'|'shop'|'world')
G.save.mark(reason)   // dirty + 이벤트 저장 예약
G.save.now(); G.save.load(); G.save.exportString(); G.save.importString(s) → {ok, summary|error}
G.save.registerSection('inventory', {get, set, version}) // 각 팀 모듈이 자기 상태 등록
```
- 원칙: 각 팀 모듈은 `G.save.registerSection`으로 자기 데이터만 직렬화 → 세이브 스키마가 팀별로 분리, 마이그레이션도 섹션 단위.
- 시간 소스는 시간·생태팀 `G.clock` 하나만 사용(UI·오디오가 `Date` 직접 호출 금지 — 테스트에서 시계 조작 가능).

|---|---|---|
| 절차적 BGM이 "삑삑 칩튠"처럼 싸게 들림 | 고퀄 인상 붕괴 | 리버브(컨볼루션 IR을 코드로 생성), 디튠·휴머나이즈(타이밍 ±8ms, 벨로시티 ±10%), 오해준이 매 진행 청취 승인 |

| 실시간 게임에서 시계 조작 | 경제 붕괴 | 감지만 하고 벌칙 없음(코지 원칙) — 단 하루 이상 역행 시 스폰 재생성 안 함 |
