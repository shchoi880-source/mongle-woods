## 1. 성격 유형 (10종: 베타 8 + 로드맵 2)

| 코드 | 이름 | 정의 | 레지스터 | 대표 어미·입버릇 | 좋아함 / 싫어함 |
|---|---|---|---|---|---|
| `sunny` | 햇살형 | 무조건 긍정, 칭찬 폭격기, 금방 들뜸 | 반말 | "~지롱!", "~거야!", 문장 끝 "!" 2개 | 꽃·노란색·파티 / 비 오는 날 혼자 있기 |
| `tidy` | 꼼꼼형 | 정리·기록·계획 중독, 예의 바름, 은근 허당 | 존댓말 | "~랍니다", "~하는 편이에요", "참고로," | 수첩·시계·정돈된 길 / 잡초·지각 |

| `brave` | 씩씩형 | 체력·도전, 모든 걸 시합으로 만듦 | 반말 | "~다구!", "가자!", "하나 둘!" | 운동기구·고기류 간식·아침 / 낮잠 |
| `prickly` | 새침형 | 겉은 쌀쌀, 속은 다정(츤). 패션 감각 | 반말 | "~거든?", "흥.", "딱히 ~는 아니고" | 옷·리본·장미 / 촌스러운 것·벌레 |
| `lazy` | 뒹굴형 | 먹고 자는 게 인생, 느긋한 철학자 | 반말 | "~해애~", "음냐", 길게 늘이기 | 간식·쿠션·이불 / 이른 아침·서두르기 |
| `chatty` | 수다형 | 소문·정보 수집가, 리액션 과장 | 반말 | "~래래!", "있잖아 있잖아", "대박" | 편지·찻잔·모임 / 비밀 지키기(못함) |
| `quirky` | 엉뚱형 | 발명가 기질, 논리 비약, 실패에 당당 | 반말 | "~인 것이다!", "가설:", "실험 결과…" | 고철·톱니·화석 / 평범함 |
| `warm` *(로드맵)* | 다정어른형 | 할머니/할아버지 같은 포근함, 옛날이야기 | 반존대 | "~했단다", "~하렴", "아이고" | 뜨개·차·화분 / 끼니 거르기 |
| `shy` *(로드맵)* | 수줍형 | 낯가림 심함, 친해지면 말이 길어짐 | 존댓말→반말(친밀 L4) | "저, 저기…", "~요…", "헤헤" | 작은 소품·책·밤 / 큰 소리·주목받기 |

**입버릇(말버릇) 시스템**
- 주민마다 고유 `catchphrase`(2~3음절 의성/의태어, 예: "몽글", "도토독")를 가진다.
- 문장 끝 부착 확률(성격별): sunny 45% / chatty 40% / quirky 35% / brave 30% / dreamy 25% / lazy 25% / prickly 15% / tidy 10% / warm 10% / shy 20%(L3+부터).
- 같은 대화창 안 연속 부착 금지(최대 1회/3문장). 친밀 L3에서 플레이어가 새 입버릇을 가르칠 수 있음(금칙어 필터 + 2~6자).
- 입버릇이 다른 주민에게 '전염'(로드맵): 친한 주민끼리 7일간 5% 확률로 상대 입버릇 사용 → 소문 대사 생성.

## 4. 일과 AI

### 4.1 기상·취침 (실제 시계 기준, ±20분 주민별 시드 랜덤)

| 성격 | 기상 | 취침 | 성격 | 기상 | 취침 |
|---|---|---|---|---|---|
| warm | 05:00 | 20:30 | sunny | 07:00 | 23:00 |
| brave | 05:30 | 21:00 | chatty | 08:00 | 24:00 |
| tidy | 06:30 | 22:00 | prickly | 09:00 | 01:00 |
| shy | 07:30 | 22:00 | dreamy | 10:00 | 02:00 |
| lazy | 10:30 | 21:30 | quirky | 11:00 | 03:00(30%: 04:00) |

### 4.2 활동과 가중치
- 활동 목록(베타 9개): `wander`(배회), `fish`(낚시), `bench`(벤치 앉기), `water`(꽃 물주기), `visit`(다른 주민 방문·대화), `sing`(노래), `read`(책), `exercise`(체조), `home`(귀가·실내).
- 하루 6구간(새벽·아침·오전·오후·저녁·밤) × 성격별 가중치표. 예: brave 아침 `exercise 40, wander 30, fish 10, ...` / lazy 오후 `bench 50, home 25, ...`.
- 활동 지속 3~12분(게임 내 실시간), 끝나면 재추첨. 직전 활동과 같은 건 가중치 ×0.3.
- `hobby` 필드가 해당 활동 +20. `mood`(0~1)가 0.3 미만이면 `home` +30, 대사 톤 '시무룩' 세트 사용.

### 4.3 상태머신 & 길찾기
- 상태: `SLEEP → WAKE → CHOOSE → WALK → DO → (TALK_PLAYER | TALK_NPC) → CHOOSE … → GO_HOME → SLEEP`.
- **플로우필드**: 맵 로드시 POI(벤치·연못 낚시자리·화단·광장·각 집 문 ≒ 20~30개)마다 4방향 BFS 거리장 계산(64×64 타일 기준 POI당 4K셀, 총 ~120KB). 주민은 현재 칸의 최소 이웃으로 이동 = O(1).
- 배회는 반경 6칸 제한 BFS로 목적지 선택. 막히면 0.5초 대기 → 2회 실패 시 옆 칸 우회 → 3회 실패 시 활동 재추첨.
- **화면 밖 시뮬레이션**: 카메라 밖 주민은 타일 이동 없이 "목적지 도착 예정 시각"만 계산해 순간 이동. 앱 재실행 시 `seed(날짜+id)`로 현재 활동을 결정적으로 복원 → 위치 튐 방지.

### 4.4 플레이어 반응
- 3칸 이내: 머리를 플레이어 쪽으로 회전(머리 스프라이트 오프셋, 0.2초 보간). 1칸 이내 정지 시 인사 말풍선.
- 감정 말풍선 10종: 느낌표·물음표·하트·음표·땀방울·반짝·졸음(Zzz)·먹구름·꽃·전구. 2초 유지, 주민당 8초 쿨다운.
- 트리거: 달리며 스침→느낌표 / 그물·낚싯대 들고 접근→물음표 / 좋아하는 색 옷→반짝 / 잡은 희귀 생물 들고 있음→전구 후 먼저 말 걸기 / 그물로 맞음→먹구름 + `fs -5`(하루 최대 -10).
- 대화 중인 주민 둘에게 다가가면 대화 내용이 말풍선으로 보임(엿듣기), 1회/주민쌍/일 `fs +1`.

### 4.5 날씨
- 비: 자기 `umbrella` 색 우산. 실외 활동 가중치 ×0.6, `home` +25. 성격 보정: brave는 비 맞으며 달리기(우산 없음), dreamy는 웅덩이 보기 활동 추가, quirky만 낚시 유지("비 오는 날 물고기 IQ 측정 중").
- 폭우/뇌우: 전원 귀가, 창가 말풍선만. 눈(로드맵): 눈사람 만들기·눈싸움 활동 추가.

## 6. 대화 시스템

### 6.1 라인 데이터 형식
```js
{ id:'l_dr_041', who:'dreamy',            // 성격 | 주민id('v_mongsil') | '*'(공용)
  sit:'greet',                             // greet|chat|gift_love|gift_meh|request|levelup|rain|bye ...
  when:{ hour:[19,23], weather:['clear'], season:['winter'], fs:[2,6],
         event:{ type:'caught_rare', within:3 }, inv:{ has:'it_star_frag' },
         flag:'!told_star', near:'v_kongja' },

  text:{ ban:'{player} 별 조각 들고 있구나… 반짝반짝 소리 들려…', jon:'...' },
  emote:'sparkle', anim:'tiptoe',
  choices:[ { t:'하나 줄까?', fs:+3, next:'l_dr_042', set:'told_star' },
            { t:'비밀이야!', fs:+1, next:'l_dr_043' } ] }
```
- `text.ban`(반말)/`text.jon`(존댓말) 중 성격 레지스터로 선택. 수작업 전용 라인은 한쪽만 써도 됨.

### 6.2 선택 알고리즘
1. 상황(`sit`) + 조건 필터 통과 라인 수집(주민id 전용 > 성격 > 공용 3층).
2. 점수 = `구체성(조건 개수)×10 + pri + 층보너스(전용 20, 성격 10) - 최근사용 패널티`.
3. 상위 점수대(최고점-5 이내)에서 가중 랜덤. 결과 없으면 공용 폴백(절대 무대사 방지).

### 6.3 반복 방지
- 주민별 최근 30개 라인 id 링버퍼(세이브됨): 포함 시 제외. 라인별 `cooldownDays`, `once`.
- 마을 전역 화제 쿨다운: 같은 날 같은 화제 태그(`rain`, `fossil_found` 등)는 3명까지만 언급, 4번째부터는 "다들 그 얘기만 하더라" 메타 대사.
- 하루 대화 3회째부터는 짧은 대사 세트(`sit:'chat_short'`)로 피로감 감소.

### 6.4 변수·조사
- `{player}`, `{nick}`(주민이 부르는 별명), `{v:친한주민}`, `{item}`, `{coin}`, `{season}`, `{time}`, `{cp}`(입버릇).
- **조사 자동 처리**: `{player|이/가}`, `{item|을/를}`, `{nick|아/야}` → 받침 판별(유니코드 (code-0xAC00)%28). 영문·숫자 이름도 끝 글자 발음 표로 처리.

### 6.5 확장(수천 줄) — 3층 구조
- **공용 템플릿**(목표: 베타 150 → 6개월 600개): 의미 단위 id(`T_RAIN_GREET`)로 `ban/jon` 두 형태만 작성.
- **성격 변환기**(어간 활용 금지, 장식만): ①레지스터 선택 ②접두 감탄사 풀(sunny "우와!", lazy "음냐…", tidy "참고로,") ③어미 치환 화이트리스트(예: tidy `~요.`→`~랍니다.`는 `~해요/~예요`로 끝날 때만, chatty `~대.`→`~래래!`) ④입버릇 부착 ⑤늘이기(lazy "~"·dreamy "…").
- **수작업 라인**: 베타 성격당 60줄 + 주민 전용 10줄 → 560줄. 템플릿 150×8 변환 = 1,200 변형. **베타 체감 ~1,700줄**, 6개월 목표 6,000+.
- 검수 도구: `G.dialog.debugDump(personality)`로 전 템플릿 변환 결과를 한 화면 출력 → 대화팀이 어색한 것만 수작업 오버라이드.

| swap(로드맵) | 주민이 가구 교환 제안 | 주민의 가구 |
- 실패해도 패널티 없음(기한 지나면 "괜찮아, 다음에!" 대사, fs 0).

**선물**: 플레이어→주민은 하루 1회 점수 반영(2번째부터 0점, 대사만). 반응은 `likes/dislikes` 태그 매칭으로 최애/좋아함/보통/싫어함 자동 분류. 주민→플레이어: L3+ 대화 시 10%, 생일엔 플레이어에게 우편 선물, 이사 시 작별 선물.

**주민 간 관계**: 호감도 행렬(-100~100), 초기값 = 성격 궁합표(+20 sunny–dreamy, +15 brave–lazy(놀림 관계), -10 tidy–quirky 등) + 랜덤 ±10. 마주치면 30% 확률로 2인 대화(공용 2인 대사 세트, 베타 40쌍). 매일 대화 시 ±1~3 변동. 50↑이면 서로 집 방문, 이름 부르는 대사에 등장. 다툼(-30↓) → 플레이어 중재 퀘스트(로드맵).

**이사(로드맵 M2부터)**: 집터 10칸. 매주 월요일 판정: 거주 30일↑ & 친밀 L4 미만 주민 중 1명 5% 확률로 "이사 고민" 상태 → 3일간 대사로 예고, 플레이어가 "가지 마" 선택 시 취소(주당 1회). L6은 전출 없음. 빈 집터는 4~7일 후 새 주민 우편 예고 → 이삿짐 트럭 연출 → 입주. 전출 주민은 '이웃 마을' 목록으로 가서 엽서를 보내고, 6개월 내 재입주 가능.

## 12. [추가] 오너 지시 반영 — 대규모 주민: 수작업 80명 + 절차 생성 방문객 6,000명

> 회의 후반 추가 지시(규모 ~6000). 위 로스터 24명은 아래 80명 후보의 1차분으로 편입한다.

**쟁점**: 하준 "생성 주민이 수작업 주민을 묻어버린다" vs 도윤 "규모 없이는 6개월 신선도 불가". 유진 "생성 이름이 이상하면 귀여움이 깨진다" vs 나래 "필터·점수로 거르면 된다".
**합의**: 역할을 나눈다. **수작업 80명 = 이야기(스토리 아크)**, **생성 방문객 = 매일의 변화(우연한 만남)**. 마을 정원 10집 중 생성 출신 입주는 최대 3집.

### 12.1 수작업 거주 후보 80명
- 성격당 8명(10종×8). 이미 정의한 24명 + 56명 추가(로드맵 월 8~10명씩 데이터 추가, 마을엔 이사로 순환).
- 추가 56명 이름 후보(종): 햇살(+5)—꿀벌(곰)·자두(돼지)·해랑(물개)·별사탕(병아리)·뽀삐(푸들) / 꼼꼼(+6)—연필(비버)·도장(두루미)·모서리(아르마딜로)·정각(고양이)·책갈피(쥐)·각설탕(양) / 꿈꾸미(+6)—이슬(사슴)·은하(고래)·노을(플라밍고)·반딧(두꺼비)·안개(백곰)·몽상(올빼미) / 씩씩(+6)—돌쇠(코뿔소)·번개(치타)·근두(캥거루)·불끈(고릴라)·쑥쑥(판다)·달려(타조) / 새침(+5)—레이스(고양이)·체리(공작)·진주(백조)·리본(토끼)·모카(족제비) / 뒹굴(+5)—찹쌀(물범)·호빵(곰)·감자(웜뱃)·누룽(돼지)·느릿(달팽이) / 수다(+5)—짹짹(앵무)·팝콘(햄스터)·소식(비둘기)·쫑알(박쥐)·라디오(미어캣) / 엉뚱(+6)—톱니(고슴도치)·나사(카멜레온)·비커(아홀로틀)·전구(도마뱀)·퓨즈(오리너구리)·자석(펭귄) / 다정어른(+6)—국화(염소)·보름(토끼)·솔잎(곰)·누룩(물소)·장독(두꺼비)·대추(원숭이) / 수줍(+6)—꽃잎(쥐)·조약(게)·살금(족제비)·소곤(나방)·도톨(다람쥐)·새싹(병아리). → 기존 24명과 합쳐 성격당 정확히 8명.
- **스토리 아크**: 주민마다 3막 7에피소드(L1·L2·L3·L4·L5×2·L6). 예) 소금: ①번역기 소개 ②부품 부탁 ③첫 실험 실패 ④물고기 소리 녹음 동행 ⑤"번역 결과: 뽀글" 대성공(?) ⑥발표회 준비 ⑦마을 앞 발표회 이벤트 + 고유 가구 '퐁당 번역기'. 에피소드당 대사 15~25줄, 1인 ~150줄 → 80명 12,000줄(수작업, 2년 계획; 6개월 안에는 40명분).

### 12.2 절차 생성 방문객(여행자) — 6,000명 풀
- **결정적 생성**: `visitorId` 0~5999. 모든 속성 = `PRNG(hash(worldSeed, visitorId))`. 세이브엔 만난 방문객의 상태만 저장 → 미만남 방문객 저장 비용 0.
- 생성 항목: 이름·종(30종)·성격(10종, 가중치 균등)·외형(종별 팔레트 6~10색 중 몸/포인트/볼터치, 귀·눈·무늬·액세서리 인덱스, 크기 0.85~1.1)·입버릇·좋아함 태그 3/싫어함 1·좋아하는 색·생일·출신 마을명·**특성(trait) 2개**·직업 역할.
- 수작업 80명과 이름 중복·외형 해시 근접(팔레트+종 동일) 시 재추첨.

**한국어 귀여운 이름 생성기** (`js/villager/names.js`)
| 패턴(비율) | 규칙 | 예 |
|---|---|---|
| 첩어 30% | 귀여운 음절 풀(120개: 뽀·몽·콩·말·쫑·도·포·토·꼬·나·리·보…) 1개 반복, 받침 ㅇ/ㄹ/ㅁ 허용 | 콩콩, 뽀뽀, 몽몽, 쫑쫑 |
| 사전+접미 35% | 음식·자연·물건 사전 400단어(떡·보리·이슬·조개·단추…) + 접미(이·니·롱·봉·순·돌·미) 0~1개 | 보리롱, 이슬이, 떡순, 조개봉 |
| 음절 조합 25% | 초성 {ㅁㄴㅂㅍㄷㄹㅇㅎㅊ}, 중성 {ㅗㅜㅏㅣㅐㅛ}, 종성 {없음60%·ㅇ·ㄹ·ㅁ} 2음절, 한글 조합식 `0xAC00+(초×21+중)×28+종` | 모루, 피롱, 누미, 다봄 |
| 사전 그대로 10% | 2~3음절 귀여운 단어 그대로 | 솜뭉치, 콩떡, 감귤 |
- **성격 연동**: brave는 ㄱ·ㄷ·ㅉ 초성·'돌/짱' 접미 가중, dreamy는 ㅁ·ㄹ·'솜/별', prickly는 외래어 느낌 사전(리본·쿠키), warm은 '순/님' 접미.
- **품질 필터**: ①금칙어 사전(비속어·신체·상표·원작 캐릭터명·실존 유명인) 부분일치 차단 ②귀여움 점수 = 열린음절 끝+2, ㅇ/ㄹ 받침+1, 된소리 2개 이상-2, 3음절 초과 금지, 점수 2 미만 재추첨 ③같은 날 방문객끼리 첫 음절 중복 금지. 6,000명 전수 생성 후 UI·대화팀이 금칙 결과를 CSV로 검수(빌드 없이 디버그 페이지에서 덤프).
- 입버릇: 성격별 의성어 풀(각 30개) 또는 이름 첫 음절 첩어+'~'(예: 보리롱 → "보보~").
- 출신 마을명: 자연어 2음절 + {골·마루·내·숲·벌} (솔바람골, 달빛마루).

**생성 주민도 말을 잘 하게 — 대사 4층**
1. 개인 전용(수작업 80명만) 2. **특성 라인**: 특성 60종(빵순이·사진가·별지기·산책광·우산수집가·편지광·길치·먹보요리사…) × 15줄 = 900줄, `{topic}`·`{origin}` 슬롯 3. 성격 변환 템플릿(6.5 그대로) 4. 공용 폴백.
- 방문객 전용 상황(`sit`): `arrive`, `about_origin`, `trait`, `trade`, `request_small`, `farewell`, `revisit`(다시 만남, 지난 만남 기억 1줄: "지난번 {item} 고마웠어!"), `invite_ask`, `invite_yes/no`.
- 조합 수: 성격10 × 특성쌍1,770 × 역할6 → 같은 대화 조합을 6개월 안에 만날 확률 사실상 0. 특성은 대사뿐 아니라 일과 가중치(사진가→`bench`·`wander` 위주, 별지기→밤 방문)에도 반영.

### 12.3 방문객이 매일을 다르게 만드는 규칙
- `daySeed = hash(worldSeed, 날짜)` → 오늘 방문객 2~4명(주말 4~5명), 역할·도착(08~13시)·출발(17~22시) 결정. 같은 날 재접속해도 동일.
- **역할 6종**: 여행자(대화·엽서 선물), 행상(희귀 아이템 3종 판매, 시스템팀 가격표), 악사(광장 연주, 금·토 밤 확률↑, 사운드팀 절차 BGM), 화가(마을 풍경 그림 → 가구 액자 판매), 수집가(특정 생물 요청, 보상 큼), 길 잃은 아이(집 찾아주기 미니 퀘스트, 저녁 전).
- 날씨·계절 보정: 비→우산 행상, 맑은 밤→별지기, 겨울→털장갑 여행자. 특별한 날(보름·유성우, 생태팀 캘린더)엔 전용 방문객.
- **거주민 반응**: 방문객과 거주민이 마주치면 2인 대화 → 다음 날 거주민 소문 대사("어제 온 {visitor}{visitor|은/는} 빵을 열두 개 샀대래!").
- **재방문**: 만난 방문객은 이후 매일 10% 슬롯 우선권(친밀 높을수록 최대 25%) → "단골 손님" 감각.

### 12.4 방문객 친밀·초대·입주
- 방문객 친밀: 별 0~5(점수 0~200, 거주민 표의 0.5배 속도). 별 2: 엽서 주고받기, 별 3: 다음 방문 날짜 예고, 별 4: **입주 초대 가능**, 별 5: 고유 생성 가구(이름+특성 조합 1점).
- 초대 조건: 빈 집터 + 별 4 + 생성 출신 거주민 3명 미만. 수락 확률 = 50% + 성격 궁합 보정(마을 거주민 평균 호감) ±20%. 거절 시 "다음에 또 올게" + 30일 내 재요청 가능.
- 입주한 생성 주민은 거주민 스키마로 승격(`gen:true, visitorId`), 미니 아크 3에피소드(특성 기반 템플릿 아크: "빵순이 → 빵 축제 열기")를 받는다.
- **저장**: 만난 방문객 1명당 ~40B(`{vid, st, met, last, mem[5]}`), 최대 400명 LRU(별 3+는 보호) → ~16KB.
- 주소록 UI: 만난 방문객 카드(외형 썸네일·별·마지막 만남). 6개월 수집 요소로 기능("오늘의 손님 도감").

### 12.5 베타 / 로드맵 / API 변경
- **베타**: 이름·외형·성격·특성 생성기 전체, 6,000 풀, 하루 2~3명 방문, 역할 3종(여행자·행상·수집가), 별 0~5 친밀, 특성 20종×15줄, 방문객 상황 대사 전체, 재방문. **입주 초대는 M2**(이사 시스템과 동시).
- **로드맵**: M1 역할 +3(악사·화가·길 잃은 아이)·특성 40종 / M2 초대·입주·미니 아크 / M3 주소록·손님 도감 / M4~6 특성 60종, 특별일 방문객, 수작업 80명 데이터 순차 추가.
- 파일: `js/villager/names.js`(이름·입버릇·마을명), `js/villager/gen.js`(결정적 생성), `js/villager/visitors.js`(일일 편성·친밀·초대), `data/lines/traits.js`, `data/lines/visitor.js`, `data/names_dict.js`(사전·금칙어).
```js
G.visitors = { today(), get(vid), gen(vid) /*결정적 생성*/, met(), befriend(vid, pts),
               canInvite(vid), invite(vid) -> 'yes'|'no', serialize(), deserialize(d, ver) };
G.villagers.promote(vid)            // 방문객 → 거주민
G.dialog.pick(speakerId, sit, ctx)  // speakerId가 'g:1234'면 4층 중 2~4층만 사용
```
- **추가 리스크**: 생성 이름의 우연한 부적절어(금칙어 + 전수 덤프 검수) / 생성 주민 대사 단조로움(특성 라인 비중↑, 수작업 거주민은 항상 1층 우선) / worldSeed 변경 시 방문객 정체성 붕괴(시드는 세이브 생성 시 고정, 마이그레이션에서 불변) / 수작업 80명 12,000줄 작성량(6개월 내 40명분만 약속).
