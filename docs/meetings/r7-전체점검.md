# 7차 회의 — PC·폰 전체 점검 (2026-11-24, v0.9.6 기준)

## 점검 방법
- PC(1000×640)와 폰(iPhone 13) 두 화면에서 자동 점검 스크립트로 주요 화면 23곳을 돌렸다.
  - 첫 화면 → 캐릭터 만들기 → 지도 고르기 → 마을
  - 잎첩 7개 탭, 지도, 상점
  - 집 안·꾸미기, 박물관, 우체통, 신문, 보리 할멈
  - 낚시, 밤·비 화면, 텃밭·목장
- 페이지 오류와 콘솔 오류를 모았고, 스크린샷 46장을 모아 직접 봤다.

## 결과
- 실행 오류 0건(두 화면 모두).
- 화면·사용성 문제 4건을 발견했다.
  1. **폰 안내 문구가 화면 밖으로 잘림**: 아래쪽 안내(hint)가 한 줄로만 나와서, 긴 문장(낚시 안내 등)이 양옆으로 넘쳤다.
  2. **폰 상점에서 살 물건이 안 보임**: 팔기 칸(가방 30칸) 아래에 사기 칸이 있어 한참 내려야 했다.
  3. **잎첩 탭을 바꿀 때 창이 들썩임**: 내용 길이에 따라 창 높이와 위치가 바뀌었다(특히 친구 탭).
  4. **가방이 꽉 찼을 때 안내 부족**: 새로 생긴 보관함을 알려 주지 않았다.
- 확인했지만 문제없음
  - 밤·비 화면 밝기, 지도 확대와 자동 이동, 집 꾸미기 버튼, 대화창, 텃밭·목장 표시.
  - 키보드 안내가 폰에 뜬 건 자동 점검이 키보드를 눌러서 생긴 것으로, 실제 폰(터치)에서는 터치 안내가 뜬다.

## 결정·조치 (v0.9.7)
1. 안내 문구 여러 줄 허용(최대 화면 90%, 가운데 정렬).
2. 상점에 「💰 팔기 / 🛒 사기」 탭. 팔 물건이 있으면 팔기, 없으면 사기 탭부터 연다. 사기 탭에 내 돈을 보여 준다.
3. 잎첩 창 높이 고정(최대 760px).
4. 가방이 꽉 차면 「집 앞에서 📦 보관함에 넣어요」까지 안내.
