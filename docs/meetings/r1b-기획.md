# 1차 회의 반론 제안서 — 기획팀 (두 번째 멤버)

- 작성: **기획팀 B — 라이브 디자이너(L)**. 장기 운영 코지게임 출시·운영 경험 기준으로 검토. 관점: **6개월 리텐션, 오너 기대치(동물의 숲급 체감 밀도), 3주차 권태**.
- 검토 대상: `docs/meetings/r1-기획.md`(이하 r1), 참고: `docs/meetings/r1-아트.md`(이하 아트안), `docs/BRIEF.md`.
- 결론 먼저: r1은 **장르 체크리스트로서는 정확하지만 "게임"으로서는 얇다.** 오너의 "너무 얇고 작다"는 지적은 맞다. 원인은 세 가지다.
  1. **볼륨이 시간대·계절 필터를 통과한 뒤 남는 양**을 계산하지 않았다(곤충 12종 → 실제 하루에 만날 수 있는 종 3~4종).
  2. **일일 루프가 '해야 할 일 목록'뿐이고 '오늘만 일어나는 일'이 없다.** 3주차에 노동이 된다.
  3. 차별화 훅(우편지기·콩알·스티커북)을 내세워 놓고 **실제 루프에서 쓰는 시간이 1~2분**이다. 이름만 오리지널이고 체감은 동숲 하위호환이다.
- 이 문서의 구성: 1. r1 항목별 비판과 수정안 → 2. 베타 볼륨 상향과 생성기 기반 실현성 → 3. 첫 14일 일별 / 1~6개월 주별 / 상시 추적 시스템 → 4. 매직 모먼트 10 → 5. 주민 스토리 아크 → 6. 비과금 보상 심리 설계 → 7. 오너 결정 사항 → 8. 베타/로드맵 분리 → 9. 합의 필요 쟁점

## 1. r1 항목별 비판과 수정안

> 형식: **[문제]** 무엇이 약한가 → **[3주차 증상]** 플레이어가 실제로 느낄 것 → **[수정]** 구체 대안. r1에서 좋은 것은 유지 표시(✔).

### 1-1. 정체성·세계관 (r1 §1)

**(1) 타이틀·세계관 「몽글숲 이야기」, 큰솜이 — ✔ 유지.** 이름·설정은 좋다. 다만 큰솜이가 "자고 있다"는 설정은 6개월 동안 **아무 일도 안 일어나는 존재**가 된다.
- [수정] 큰솜이에 **'뒤척임' 이벤트**를 붙인다. 월 1회 실제 시각 기준 랜덤 날 큰솜이가 뒤척이면 마을 지형 소규모 변화(새 오솔길 1개, 바위 위치 변경, 숨은 동굴 입구 노출). 6개월에 6번, 매번 "마을이 살아있다"는 증거. 지형 변화는 월드팀의 **사전 정의 패치 6종**(타일 diff)으로 구현 — 생성 아님, 수제.
- [수정] 큰솜이의 **꿈**: 등불이 켜질 때마다 큰솜이 꿈 조각(짧은 그림책 컷신 4컷)이 열린다. 10개 모으면 몽글숲의 기원 이야기 완성. 메타 목표에 서사를 입힌다.

**(2) 우편지기 역할 — 훅인데 쓰이지 않음.** r1 하루 루프에서 우편은 "우체통 확인 1분"과 튜토리얼 배달 1회가 전부다.
- [3주차 증상] 플레이어는 자기가 우편지기라는 걸 잊는다. 그냥 동숲 주민이다.
- [수정] **배달 가방 시스템**을 일일 루프의 축으로: 매일 아침 우체국에서 **배달물 2~5개**(편지·소포·엽서)를 받는다. 주민 간 편지(A→B)를 실제로 들고 가서 전해야 한다.
  - 배달 시 수신 주민의 **반응 대사 + 그 자리에서 답장 의뢰**(30%) → 관계망이 플레이어를 통해 돌아간다.
  - 배달 완료 수에 따라 **우편지기 등급 1~10**(가방 크기, 자전거 → 이동속도 +15%, 우체국 확장, 우표 디자인 권한).
  - **우표 수집**: 배달물에는 우표가 붙어 있고, 배달 후 1장 획득. 우표 120종(계절·주민·이벤트별). 우표첩이 스티커북과 별도의 수집 축.
  - 배달은 **강제 아님**: 안 하면 우체국에 쌓이고(최대 8) 보리 할멈이 "천천히 해요" 한마디. 페널티 없음.

**(3) 콩알 — 좋은 훅, 성장이 없음.** 성향 5종 털색 변화는 "한 번 보고 끝"인 변화다. 베타 성향 2종은 더 얇다.
- [수정] 콩알에 **3개 축**을 준다.
  1. **성장 단계 4단계**(솜씨앗→솜뭉치→솜구름→솜별): 30일·75일·150일 + 함께한 활동 수 조건. 단계마다 새 능력(꼬물 감지 반경 증가, 물고기 그림자 희귀도 색 표시, 밤에 길 비춤, 숨은 비밀 감지).
  2. **아침 꿈 이야기**: 매일 첫 접속 시 콩알이 어젯밤 꾼 꿈을 한 줄 말한다. 꿈 = **오늘의 힌트 암호**("물가에서 파란 불꽃이 춤추는 꿈을 꿨어" → 오늘 밤 희귀 반딧불 확정). 꿈 풀 베타 80개.
  3. **콩알 꾸미기**: 콩알용 모자·리본 20종(베타 8). 수집 축 하나 추가, 사진 모드 주인공.
- 성향은 베타 5종 전부(색 팔레트 교체 + 대사 톤 변경이라 비용 작음).

**(4) 스티커북 — 베타 1페이지는 죽은 기능.** 1페이지 12칸이면 첫날 저녁에 끝난다.
- [수정] 베타 스티커북 **10페이지**(곤충/물고기/화석/주민/이벤트/계절/비밀 등), 스티커는 획득 즉시 자동 생성(아이콘 생성기 재사용 → 추가 아트 0). 페이지 꾸미기: 스티커 자유 배치·회전·크기 3단계. 이게 "도감=꾸미기 콘텐츠"의 실제 구현이다.

**(5) 말랑 반응 규칙 — ✔ 유지 + 확장.** 0.15초 squash와 이모트 규칙은 좋다. 그러나 "모든 대상이 같은 반응"은 1주 뒤 배경이 된다.
- [수정] **숨은 반응 100개 목록**을 데이터로: 같은 나무를 20번 흔들면 다람쥐가 떨어져 화냄, 우체통을 연타하면 뚜껑이 삐짐, 비 오는 날 우산 없이 주민에게 가면 주민이 우산 씌워줌, 밤에 가로등 아래 5초 서 있으면 나방 모임, 눈사람 옆에 앉으면 눈사람이 고개 돌림 등. 비밀 도장(§3-3)과 연결 → 찾는 재미 자체가 콘텐츠.

### 1-2. 코어 루프 (r1 §2)

**(6) 하루 루프 = 체크리스트 7행.** 우체통→소식→화석4·돌6·나무→부탁3→인사6→낚시곤충→판매. 장르 공식 그대로이고, **매일 똑같다.**
- [3주차 증상] "화석 4개 파고 돌 6번 치고 인사 6번" = 15분 출석 노동. 동숲 2년차 이탈 패턴이 우리 게임에서는 3주차에 온다(우리는 볼륨이 더 작으니까).
- [수정] 하루 = **고정 루틴(≤10분) + 오늘의 사건 1~3개 + 진행 중 이야기 1개**로 구조화.
  - **오늘의 사건 덱**: 사건 카드 베타 60장(가중 랜덤, 최근 14일 내 중복 금지). 예: 주민 둘이 다퉈서 화해 편지 배달, 강에 떠내려온 병, 길 잃은 아기 오리 3마리를 엄마에게, 갑자기 버섯 고리 발생, 우체통에 익명 편지, 상점 재고 정리 세일, 주민이 이사 갈까 고민(진짜 이사는 안 감 — 베타) 등.
  - **진행 중 이야기**: 주민 스토리 아크(§5) 중 하나가 항상 진행 중. "내일 이어짐"이 매일 접속 이유가 된다.
  - 보리 할멈의 몽글소식 대신 **마을 게시판**: 오늘 사건·생일·날씨·희귀 힌트가 붙는다. 매일 눈으로 확인 가능한 "오늘 다름".

**(7) 낚시/곤충 무제한 + 희귀도 분산 — 원칙 ✔, 볼륨 ✘.** 12종으로 시간대 4구간·날씨 필터를 돌리면 **한 시점에 출현 가능한 종이 3~5종**이다.
- [3주차 증상] 1주차 둘째 날이면 "또 붕어"다. 무제한이 오히려 반복 체감을 증폭.
- [수정] (오너 최신 지시 반영) 베타 **기본종 곤충 60·물고기 60, 각 종 변종 6단계 = 도감 항목 360+360**. 한 시점 출현 가능 기본종 **12~18종**을 보장하는 출현 테이블 규칙을 시간·생태팀에 요청. 변종(거대·알비노·희귀무늬·황금·계절색)은 §2-4 — 도감 완성 후에도 잡을 이유가 구조적으로 생긴다.

**(8) 주간 루프 — 요일 4개만 의미, 그나마 대회는 싱글에서 경쟁감 없음.**
- [수정] 7요일 모두 성격을 준다(§3-1 참조). 대회는 "주민 기록과 비교"가 아니라 **주민이 직접 참가해 결과 발표회 + 트로피 가구 + 주민이 진심으로 축하/분해함**. 주민 반응이 보상의 절반이다. 주민 기록은 플레이어 실력에 맞춰 ±20% 보정(항상 접전).

**(9) 계절 루프 — 계절당 생물 25, 세트 1, 이벤트 2: 정식 기준으로도 얇다.**
- [수정] 계절당: 신규 생물 30(곤충12·물고기12·해변6), 계절 가구 세트 2(24점), 계절 의상 8, 계절 레시피 10, 계절 우표 10, **계절 이벤트 1대형 + 4소형**, 계절 한정 주민 대사 주민당 30줄. 계절 전환일 자체를 이벤트로("첫눈 아침", "벚꽃 첫날").

### 1-3. 진행 곡선 (r1 §3)

**(10) 6개월 표가 집 대출 표다.** 집 확장 4단계 + 박물관 증축 = 동숲 1년차 골격 복사. 오너가 "동숲급"이라 한 건 동숲 구조 복제가 아니라 **동숲의 체감 밀도**를 말한 것이다.
- [수정] 진행 축을 **5개로 분산**: ① 집(대출) ② 마을 공공사업(주민 제안 → 투표 → 모금 → 완공 이벤트) ③ 우편지기 등급 ④ 등불 10개 ⑤ 주민 스토리 시즌. 어느 주에 보더라도 최소 2개 축이 "다음 단계 직전"이도록 일정 배치(§3-2 주별 표).

**(11) 3~6개월 해금이 숫자 연장.** 지하실·고급 변종·화석관 완성·외관 커스텀 = 새 감정 없음.
- [3주차가 아닌 3개월차 증상] 동숲 실제 이탈 구간. 여기서 우리가 이겨야 한다.
- [수정] 3~6개월에 **새 장소 3곳**(안개 연못 2개월차로 당김, 큰솜이 꼬리 끝 '별빛 해안' 4개월, 큰솜이 귀 속 '바람굴' 5개월), **주민 이사 드라마**(떠나는 주민 작별 편지 → 새 주민), **마을 신문**(주간, 플레이어 행동이 기사화), **2번째 계절 전환**이 들어가야 한다.

**(12) 등불 10개 — ✔ 방향 좋음, 조건 단조.** "기증 30", "옷 30벌", "꽃 변종 20" = 수치 목표 나열. 18일에 1개 = 중간에 2~3주 아무 변화 없는 구간 발생.
- [수정] 등불마다 ①**주민 1명의 스토리 아크 완결**을 조건에 포함 ②점등 시 **마을 한 구역의 영구 시각 변화**(밤 조명, 반딧불 서식지, 새 소리) ③**점등식 이벤트**(주민 전원 광장 모임, 큰솜이 꿈 컷신). 등불 사이 간격 최대 21일, 등불 사이에 **반 등불(작은 촛불) 2개**씩 중간 보상.

**(13) 대출 총액 1,277,000◎ + 수입 40~80k/일 — 방울이 대출밖에 쓸 데가 없다.** 6개월 동안 플레이어 방울 흐름의 70%가 대출로 간다는 계산. 대출 끝나면 방울 무의미.
- [수정] 방울 싱크 8종 이상: 공공사업 기부, 가구 리폼(색 바꾸기 1회 2,000◎), 행상 희귀품, 콩알 꾸미기, 우표 주문 인쇄, 주민 생일 선물 주문, 마을 꽃길 포장, 사진 액자 제작. 대출은 **이자 없음 + 기간 없음**(r1과 동일, ✔).

### 1-4. 볼륨·이벤트 (r1 §4, §5)

**(14) 베타 볼륨 표 — 아트팀보다 작다.** 아트안은 이미 곤충·물고기 30/30, 주민 큐레이션 16명을 제시했는데 기획이 12/12, 6명을 요구했다. **기획이 아트보다 겁을 먹은 상태.** 기획은 상한을 제시하고 다른 팀이 깎는 구조여야 한다.
- [수정] §2 표로 전면 상향. 오너 최신 지시(곤충·물고기 각 1,200 도감 항목, 주민 6,000, 가구 60,000)는 **"수제 핵심 + 절차적 변종"** 모델로 수용(§2-4). 이 문서의 초안 수치(30/30/90)는 폐기.

**(15) 주민 6명·성격 4종·성격당 80줄.** 계산: 주민 6명 × 하루 대화 평균 4줄 = 24줄/일. 같은 성격 주민 2명이 80줄 공유 → **성격 풀 1회 순환 약 7일.** 2주차에 "이 말 들었는데"가 확정이다.
- [수정] 주민 8명 × **성격 8종(1명당 1성격)**, 대사 = 성격 공통 풀 120 + **개인 고유 120** + 스토리 아크 대사 + 상황 태그 조건(날씨·시간·계절·친밀도·최근 플레이어 행동). 주민당 사용 가능 대사 베타 **≥250줄**, 반복 억제 규칙: 같은 줄 재사용 최소 21일 간격.

**(16) 베타 이벤트 2개(별똥별·낚시대회).** 베타 기간에 플레이어는 "이벤트가 있는 게임"이라는 인식을 갖지 못한다.

### 2-2. 왜 가능한가 — 데이터 주도 생성기

> 원칙: **사람은 "규칙과 표"를 쓰고, 코드가 "조합"을 만든다. 단 조합 결과는 큐레이션해서 데이터로 고정한다**(아트안 도윤 원칙 준수: 랜덤 런타임 생성 금지).

1. **생물 생성기**(아트안 §5): 곤충 템플릿 8 × 파라미터, 물고기 실루엣 7 × 파라미터. 기획이 넣을 것은 종당 1행 데이터: `{id, name, tpl, params, habitat, hours, months, weather, rarity, size[min,max], price, flavorText}`. 60+60행 = 기획 작업 약 4일(설명문 포함). 변종 6단계는 규칙 테이블 1장이 전 종에 적용(종별 행 추가 없음).
2. **가구 생성기**: 기본형 40(베타) × 재질 8 × 색 최대 12 → 유효 조합 3,000+ 카탈로그 항목 + 수제 세트 3개(숲속 오두막·바닷가·우체국 테마) 24점. 기획 데이터는 기본형 1행 + 재질·색 허용표.
3. **옷 생성기**: 아트 아바타의 상의 6·하의 4 형태를 10형태로 늘리고 팔레트 24색 중 지정 → 30종. 원피스 2형태 추가 요청.
4. **대사 문법(Grammar) 생성기**: 대사는 `템플릿 + 슬롯 + 조건 태그`.
   ```js
   { id:'dubu_rain_03', who:'dubu', tags:{weather:'rain', minFriend:2},
     text:'비 오는 날엔 {food}을(를) 끓여 먹어야 해… {player}도 먹을래?',
     slots:{ food:['호박죽','감자수프','버섯탕'] } }
   ```
   - 슬롯 평균 3 → 줄 1개가 체감 3변형. 주민당 수작업 90줄 × 슬롯 = 체감 250+.
   - 반복 억제: 최근 사용 줄 ID 링버퍼(주민당 64, 세이브에 저장, 비트 압축 시 주민당 ~200B).
5. **편지 생성기**: `인사(계절·날씨) + 본문(사건/관계/선물 답례) + 맺음(성격)` 3단 조합. 각 단 30~50조각 → 조합 수천, 큐레이션된 고정 편지 150은 스토리용.
6. **이벤트 엔진**: `{id, trigger:{date|weather|random|flag}, schedule, actors[], script:[...], rewards[], stamp}`. 스크립트 명령 15개(이동·대사·이모트·카메라·파티클·스폰·아이템 지급·플래그). 엔진 1회 구현 후 이벤트당 반나절 데이터 작업.
7. **사건 카드 덱**: `{id, weight, cooldownDays, conditions, setup, resolve, reward}`. 60장 = 기획 3~4일.
8. **도장(업적)/비밀**: 카운터 훅 기반 `{id, counter, threshold, hidden}`. 엔진은 이벤트 버스 하나로 해결.

- **공수 추정(기획팀 2인 기준)**: 데이터 작성 총 약 18~22 작업일. 엔진 측 추가 구현(대사 문법·이벤트 엔진·사건 덱·도장)은 각 팀 1~3일. 즉 **볼륨을 2.5배로 올리는 비용은 주로 기획 데이터 작업이고, 코드 비용은 엔진 4종 추가에 그친다.**
- **세이브 예산**: 도감·도장·우표·비밀 = 비트필드(총 ~120B), 크기 기록 Uint16 배열(~400B), 대사 링버퍼(~2KB), 편지함(최근 60통 ID+슬롯값 ~6KB). 합계 r1 상한 500KB 대비 여유 충분.

### 2-4. 대규모 카탈로그 모델 — "수제 핵심 + 절차적 변종" (오너 최신 지시 반영)

> 오너 목표: 곤충 1,200 · 물고기 1,200 · 주민 6,000 · 가구 60,000. 라이브 운영자로서 **경고 하나**: 숫자가 크면 "다 비슷한 1,200개"가 되는 순간 리텐션은 오히려 떨어진다. 그래서 규칙은 하나 — **기본종은 손으로, 변종은 규칙으로, 그리고 변종마다 '찾는 방법'이 달라야 한다.** 숫자가 아니라 **사냥 방식의 다양성**이 의미를 만든다.

#### (A) 곤충·물고기: 기본종 200 × 변종 6 = 도감 1,200 (각)
- **기본종(수제)**: 이름·실루엣·서식지·시간대·출현 월·크기 범위·가격·도감 설명문을 종마다 직접 작성. 생성기는 그리기만 담당. 같은 템플릿 종끼리 색·무늬·크기 중 2축 이상 차이(아트 검토 규칙 유지).
- **변종 6단계** — 변종마다 다른 조건 축을 쓴다(같은 방식으로 6번 잡게 하지 않는다):

| 변종 | 확률/조건 | 찾는 방법(사냥 축) | 도감 표시 |
|------|-----------|--------------------|-----------|
| ① 보통 | 기본 | 시간·장소 | 기본 스티커 |
| ② 거대 | 크기 상위 3% (크기 분포 정규, 꼬리 절단) | **반복 포획** — 크기 기록 경쟁 | 금테 + 실측 크기 |
| ③ 알비노 | 1/400, 안개·눈 날씨에 ×3 | **날씨 축** | 흰 스티커 + 붉은 눈 |
| ④ 희귀무늬 | 1/250, 종별 고유 무늬 2안 중 1 (생성기 무늬 파라미터 시드 고정) | **장소 축** — 종마다 "무늬 잘 나오는 지점" 1곳(마을 신문·콩알 꿈 힌트) | 무늬 확대 컷 |
| ⑤ 황금 | 1/1,000, 등불 점등 수에 따라 해금(등불 3 이후만 출현) | **진행 축** — 후반 목표 | 반짝 애니 스티커 |
| ⑥ 계절색 | 기본 출현 월 중 **마지막 2주에만**, 1/60 | **달력 축** — 놓치면 1년 | 계절 테두리 |

- 수치 검증(6개월 플레이어, 하루 낚시 평균 25회 × 180일 = 4,500회, 곤충 비슷): 6개월 시점 예상 달성률 — 보통 ~70%(계절 절반만 지남), 거대 ~35%, 계절색 ~25%, 희귀무늬 ~15%, 알비노 ~10%, 황금 ~3%. **전체 1,200 중 약 25~30% = 300~360칸.** 6개월 뒤에도 책의 70%가 남는다 → 2년차 동기. 반대로 "아무것도 못 채운" 느낌을 막기 위해 **기본종 페이지는 따로 % 표시**(보통 변종 기준 달성률이 메인 지표).
- **크기 기록**: 종별 최대 크기 Uint16 저장, 주민 기록·마을 신문 "이주의 기록" 연동. 거대 기준 돌파 시 주민이 직접 보러 옴(말랑 반응).
- **지역·시간 한정 종**: 기본종 200 중 **40종은 특정 구역 전용**(안개 연못·별빛 해안·바람굴 등 로드맵 장소), **30종은 특정 이벤트 밤 전용**(별똥별·반딧불 강·첫눈). 장소 해금이 곧 도감 해금이 되어 월별 해금 곡선과 맞물림.
- **변종 연출 규칙**: 변종 획득은 확정 연출 단계를 한 단계씩 올림(거대=드문, 알비노·무늬=드문+, 황금=전설). 변종 첫 획득 시 콩알 반응 + 스티커 즉시 발급.
- 베타: 기본종 60×6 = **360칸씩**, 변종 시스템 6단계 전부 동작(황금은 베타 기간 등불 조건 완화 → 등불 1 이후 출현).

#### (B) 주민: 수제 상주 후보 80 + 절차적 방문객(무한, 시드 고정)
- **수제 80**: 스토리 아크·고유 대사·취향·생일이 있는 "이사 올 수 있는 진짜 주민". 마을 동시 상주 최대 12. 6개월 동안 만나는 수제 주민 약 14~18명 → 80명 전원 만나려면 수년.
- **절차적 방문객(떠돌이 손님)**: `seed = hash(세이브ID, 날짜, 슬롯)` → 종(20)·털색·무늬·옷·성격 8·말버릇 1(40종 풀)·직업 1(여행 사진가·씨앗 장수·편지 친구 찾는 이 등 24종)·이름(음절 조합 생성기, 금칙어 필터). 조합 수 수천~수만, 세이브엔 만난 방문객 시드만 저장(1명 4B).
  - 빈도: 하루 0~2명(광장·해변·다리). 하루 1명은 거의 확정 → **"오늘의 손님"**이 매일 서프라이즈 축이 된다.
  - **방문객 도감(손님 방명록)**: 만난 방문객 자동 기록 + 직업별 수집 페이지(24직업 × 성격 8 = 192칸 "손님 유형 도감"). 방명록 숫자는 6개월에 ~250명.
  - **초대 이사**: 같은 방문객을 **3번 만나고 선물 2회**하면 "이 마을 좋네요" → 빈 집터가 있으면 이사 초대 가능. 절차적 주민은 스토리 아크 대신 **템플릿 아크 6종**(정착·친구 사귀기·직업 가게 열기 등)을 받는다. 수제 주민과 구분되는 표식 없음(플레이어가 키운 주민이 "나만의 주민"이 된다).
  - 품질 게이트: 방문객 외형은 아트 실루엣 테스트 통과한 프리셋 범위 안에서만 시드 → "못생긴 조합" 방지(아트안 도윤 원칙). 이름 생성은 음절표 + 금칙어 리스트.
- 베타: 수제 상주 8 + 방문객 생성기 동작(직업 8종, 방명록 64칸) + 초대 이사 1회 가능.

#### (C) 가구: 기본형 600 × 재질 × 색 = 60,000 카탈로그
- 공식: 기본형 600(수제 그리기 함수 + 고유 디테일) × 유효 재질 평균 4 × 유효 색 평균 25 ≈ 60,000. 색은 아트 팔레트 24색 + 특수(무지개 염료·별조각·황금) 3.
- **의미 부여 규칙** (60,000개가 노이즈가 되지 않게):
  1. 카탈로그 완성 단위는 **기본형**(600)이 메인 지표, 재질·색은 "컬러 칩" 수집(기본형 페이지에 칩이 채워짐).
  2. **획득 경로가 다른 칩**: 기본색은 상점, 파스텔은 행상, 특수 3색은 이벤트·리폼 재료로만 → 색 칩 자체가 희귀도.
  3. **세트 보너스**: 같은 재질 6기본형 배치 시 방 테마 이름 부여 + 주민 반응("숲속 오두막 같아!").
  4. **리폼**: 가진 가구를 재질·색 변경(방울 싱크) → 카탈로그에 칩 등록. 구매 없이도 카탈로그가 늘어나는 경로.
  5. 카탈로그 UI: 기본형 단위 그리드 + 칩, 검색·필터(재질/색/세트/미보유). 60,000을 리스트로 보여주지 않는다.
- 베타: 기본형 **40 → 카탈로그 3,000+**, 카탈로그 UI·리폼·컬러 칩 동작. 6개월 로드맵: 월 +80 기본형.
- 데이터: 카탈로그 항목은 저장하지 않고 `formId×matId×colorId`를 비트맵으로(60,000비트 = 7.5KB) 저장.

## 4. 매직 모먼트 10

> 플레이어가 6개월 뒤 친구에게 "이 게임 이런 장면 있어"라고 말할 장면. 각 장면은 시스템이 **자동으로** 만들어 내야 한다(수제 컷신은 3개 이하).

1. **첫 밤, 텐트 안.** 첫날 처음으로 텐트 안에서 잠들기 버튼을 누르면, 콩알이 모자에서 내려와 베개 옆에 동그랗게 몸을 말고 "내일 꿈 얘기 해줄게" 한다. 텐트 천에 비 소리가 들리면(비 오는 날) 콩알이 이불 속으로 파고든다.
   - 시스템: 콩알 꿈 시스템, 날씨, 말랑 반응. 수제 컷신 1.
2. **꿈이 맞았다.** 콩알이 "파란 불꽃이 물 위에서 춤추는 꿈"을 말한 날 밤, 강가에서 실제로 푸른 반딧불이 떼를 만난다. 콩알이 "봐! 봐!" 하고 털이 부풀어 오른다.
   - 시스템: 꿈 풀의 힌트 태그 ↔ 출현 테이블 강제 스폰.
3. **주민이 나를 기억한다.** 2주 전 아무 생각 없이 두부에게 준 '조개껍데기'가, 두부 집에 갔더니 창가에 놓여 있다. 말을 걸면 "네가 준 거야. 볼 때마다 바다 냄새 나."
   - 시스템: 선물 이력 저장(주민당 최근 선물 10개) → 주민 집 인테리어 슬롯에 반영 + 회상 대사 태그.
4. **비 오는 날 우산.** 우산 없이 비 맞고 다니다 모카에게 말을 걸면, 모카가 무심하게 자기 우산을 씌워주며 "…감기 걸려." 다음 날 우체통에 모카 이름 없는 소포: 우산 1개.
   - 시스템: 숨은 반응(비밀 #) + 지연 소포.
5. **편지가 엇갈렸다.** 라임과 도토가 다퉈서 각자 플레이어에게 "전해줘" 편지를 준다. 두 편지를 다 전하고 나면 다음 날 아침 둘이 광장 벤치에 같이 앉아 있고, 플레이어에게 공동 서명 편지가 온다.
   - 시스템: 사건 카드 + 배달 시스템 + 주민 일과 오버라이드.
6. **생일 서프라이즈의 반대편.** 플레이어 생일(캐릭터 생성 시 입력, 선택) 아침, 집 문을 열면 주민 전원이 문 앞에 모여 있다. 각자 직접 만든 선물. 콩알은 자기 털 한 올로 만든 리본을 준다.
   - 시스템: 이벤트 엔진 + 주민 취향 데이터로 선물 결정. 수제 컷신 2.
7. **떠나는 친구의 마지막 배달.** 떠나기로 한 주민의 이사 전날, 마지막 배달물이 "플레이어 앞"이다. 발신인은 그 주민. 열어보면 함께 찍은(이벤트 시 자동 저장된) 사진 액자 가구와, 지금까지 플레이어가 그 주민에게 배달해준 편지 수가 적혀 있다.
   - 시스템: 관계 카운터 기록 + 사진 이벤트 기록 + 편지 생성기.
8. **첫눈 아침.** 실제 첫 겨울날(또는 첫 눈 날씨) 첫 접속 시, 화면이 하얗게 페이드인되고 주민들이 광장에서 처음 보는 눈사람을 만들고 있다. 플레이어가 마지막 눈덩이를 올려주면 눈사람이 윙크한다.
   - 시스템: 계절 전환 이벤트 + 말랑 반응.
9. **내가 만든 우표가 돌아왔다.** 우편 등급 5에 디자인한 우표(스티커북 꾸미기 도구 재사용)가, 일주일 뒤 주민이 다른 주민에게 보내는 편지에 붙어서 내 배달 가방에 들어 있다. 주민 대사: "이 우표 요즘 유행이래."
   - 시스템: 사용자 생성 우표 → 우표 풀에 가중치 높게 편입.
10. **큰솜이가 깨어난다.** 6개월째 마지막 등불이 켜지는 밤, 마을 전체가 천천히 위로 들린다(큰솜이가 기지개). 하늘 가까이에서 별똥별이 쏟아지고, 큰솜이의 한 줄 대사: "…너였구나, 편지 소리." 그동안 배달한 편지 총 수가 별자리로 그려진다.
    - 시스템: 등불 메타 + 배달 카운터 + 별똥별 파티클. 수제 컷신 3.

## 5. 주민 스토리 아크 (베타 8명)

> 형식: 이름(종·성격) — 핵심 결핍 / 아크 주차별 비트 / 플레이어가 하는 일 / 보상. 아크는 **주민 친밀도 + 날짜 경과**로 진행, 1비트 = 3~5일. 아크 동시 진행 최대 2개(과부하 방지). 성격 8종: 활발·느긋·시크·걱정·수다·신비·꼬마·수줍음.

### 5-1. 두부 (곰·느긋) — "할머니의 호박죽"
- 결핍: 돌아가신 할머니 호박죽 맛을 기억 못 함.
- W1: 비 오는 날 "그 맛이 안 나" 첫 언급. W2: 할머니 옛 편지 조각 3장이 우체국 분실함에서 발견(플레이어가 배달 중 발견). W3: 재료 퍼즐 — 편지 조각의 힌트(가을 버섯·꿀·숲 도토리)를 채집. W4: 두부 집에서 함께 끓이기 미니 연출, 주민 전원 시식회.
- 보상: '할머니의 냄비' 가구, 호박죽 레시피, 등불 1 조건 충족.

### 5-2. 라임 (토끼·활발) — "마을 한 바퀴 기록"
- 결핍: 예전 달리기 대회에서 넘어진 뒤 경쟁이 무서움.
- W1: 매일 아침 혼자 달리는 모습. W2: 플레이어에게 기록 재기 부탁(미니 타이밍 게임). W3: 대회 신청서를 썼다 찢음 → 플레이어가 찢어진 신청서를 주워서 배달할지 선택. W4: 토요 대회 특별 종목 '마을 한 바퀴' 개최, 라임 완주(등수 무관, 완주 연출).
- 보상: 러닝화(이동 속도 +5% 신발), 라임 사진.

### 5-3. 모카 (고양이·시크) — "보여주지 않는 그림"
- 결핍: 그림을 그리지만 아무에게도 안 보여줌.
- W1: 모카 집 이젤에 천이 덮여 있음. W2: 플레이어가 경치 좋은 장소 3곳 사진(사진 모드) 가져다주기. W3: 모카가 몰래 그린 플레이어 초상화를 플레이어가 우연히 발견 → 모카 삐짐(이모트), 이틀 뒤 화해 편지. W4~5: 박물관 미술 코너 첫 전시회 — 모카 그림 4점(그림 = 마을 실제 장소 렌더를 수채 필터로 캐시).
- 보상: 모카가 그린 '우리 집' 그림(플레이어 집 외관 렌더), 등불 2.

### 5-4. 도토 (다람쥐·걱정) — "잊어버린 도토리 지도"
- 결핍: 겨울 대비로 숨긴 도토리 장소를 다 잊음, 매사 불안.
- W1: 숲에서 땅 파며 울상. W2: 도토가 그린 엉망 지도 → 플레이어가 지형 단서로 4곳 발굴(보물찾기 미니게임, 삽 재사용). W3: 마지막 1곳이 큰솜이 뒤척임으로 이동해 있음 → 콩알 감지로 발견. W4: 도토가 "다음엔 기록해둘래"라며 **플레이어와 공동 일기장** 시작(이후 매주 도토 일기 1페이지가 편지로 옴).
- 보상: 도토리 선반 가구, 비밀 지도 기능(숨은 비밀 1개 위치 공개).

### 5-5. 퐁당 (오리·수다) — "몽글 마을 신문"
- 결핍: 소문만 퍼뜨린다는 평판, 진짜 기자가 되고 싶음.
- W1: 잘못된 소문 퍼뜨려 주민 간 오해. W2: 플레이어가 사실 확인 배달(관련 주민 3명 증언 듣기). W3: 정정 기사 → 신문 창간 결심, 이름 투표(3안). W4: **마을 신문 1호** 발행.
- 보상: 마을 신문 시스템 상시화(매주 월 — 플레이어 기록·주민 소식·다음 주 날씨 예보·숨은 비밀 힌트 1개). 이게 퐁당 아크의 진짜 보상이자 6개월 콘텐츠 엔진.

### 5-6. 단풍 (여우·신비) — "주소 없는 편지" (메인 미스터리, 6개월)
- 결핍: 밤에만 나타나고, 오래전 누군가에게 보내지 못한 편지를 들고 있음.
- 1개월: 밤 22시 이후에만 다리 위에 서 있음. 대화 거의 없음. 가끔 우체통에 **주소 없는 편지**(수신인 불명, 배달 불가) — 우체국 분실함에 보관.
- 2개월: 분실 편지가 5통 쌓이면 보리 할멈이 "옛 우편지기"의 존재를 처음 이야기.
- 3~4개월: 별빛 해안에서 옛 우편지기의 낡은 가방 발견(우편 등급 연동).
- 5개월: 비밀 우체통 → 단풍의 편지 수신인이 **큰솜이**였음이 밝혀짐.
- 6개월: 한 해 축제 밤, 플레이어가 마침내 그 편지를 큰솜이에게 배달(최종 배달). 단풍이 처음으로 낮에 광장에 나타난다.
- 보상: 옛 우편지기 모자, 큰솜이 꿈 조각 마지막, 엔딩 컷신 연결.
- 베타에서는 **1개월 분량(1~2단계)**까지만 구현, 미스터리 떡밥이 베타 이후를 기대하게 만든다.

### 5-7. 콩떡 (햄스터·꼬마) — "고향에 보내는 편지"
- 결핍: 가장 늦게 이사 온 막내, 밤마다 고향 생각.
- W1: 이사 직후 집 밖으로 안 나옴. W2: 플레이어가 고향 앞 편지 배달 의뢰 → 우편 등급 시스템 소개(먼 곳 배달은 "몽글바람 우편"으로 보냄, 3일 뒤 답장). W3: 고향 답장 도착 + 고향 씨앗 동봉 → 플레이어 화분에서 함께 키우기. W4: 꽃이 피면 콩떡이 "여기도 고향이 될 수 있겠다" — 광장에 처음 나와 다른 주민과 놀기 시작.
- 보상: 콩떡 고향 꽃(교배 불가 고유 꽃 1), 콩떡 사진.

### 5-8. 보송 (판다·수줍음) — "말 대신 꽃말"
- 결핍: 말을 잘 못해서 대화가 "…" 위주.
- W1: 대화 시 이모트만. 보송 집 앞 화단이 매일 다른 꽃 배열. W2: 플레이어가 **꽃말 사전**(보리 할멈) 받음 → 화단 배열이 메시지임을 발견("고마워", "같이 놀자"). W3: 플레이어가 자기 화분으로 꽃말 답장 → 보송이 처음 한 문장 말함. W4: 보송과 함께 마을 입구 화단 공공사업.
- 보상: 꽃말 사전(꽃 교배에 의미 레이어 추가), 화단 공공사업 해금, 보송 손편지(대사 대신 그림편지 고유 형식).

### 5-9. 아크 운영 규칙
- 비트 사이에 **주민 간 반응**을 넣는다: 라임 아크 진행 중엔 다른 주민도 "라임 요즘 달리더라" 대사. 아크 1개당 타 주민 반응 대사 각 2줄 = 14줄.
- 아크 완결 → 그 주민 **'단골 대사' 변경**(성장한 모습 반영). 아크 전/후 대사 풀이 달라야 성장이 보인다.
- 시즌 2 아크(4개월~): 주민 간 관계 아크(라임×도토 이웃 싸움과 화해, 모카×보송 공동 작품 등) 4개 로드맵.

## 6. 비과금 보상 심리 설계

> 우리는 과금이 없다. 그러니 "다시 오게 하는 힘"은 전적으로 **기대·호기심·애착**이어야 한다. 손실 공포(FOMO)는 최소화하되, **"오늘의 것"은 반드시 존재**해야 한다.

### 6-1. 가변 보상 (Variable Ratio)
- 모든 반복 행동에 **3층 보상 구조**: 기본(확정) / 가끔(10~20%) / 드문(1~3%) / 전설(0.2~0.7%).
  | 행동 | 기본 | 가끔 | 드문 | 전설 |
  |------|------|------|------|------|
  | 나무 흔들기 | 잎 파티클 | 과일·나뭇가지 15% | 가구 낙하(1일 1회 상한) 3% | 다람쥐 보물 상자 0.5% |
  | 돌 두드리기 | 돌 | 광석 15% | 희귀 광석 3% | 화석 원석 0.5% |
  | 낚시 | 흔한 종 | 보통 28% | 귀함 10% | 전설 2% / 희귀 변종(알비노·무늬·황금) 합계 ~0.75% |
  | 해변 걷기 | 조개 | 병 편지 10% | 별모래 2% | 인어 유리구슬 0.3% |
  | 배달 | 우표 1 | 답례 간식 20% | 답례 가구 3% | 주민 비밀 이야기 1% |
- **연출 차등**: 기본 0.4초, 가끔 1초 들어올리기, 드문 1.5초 + 반짝 효과음, 전설 2.5초 + 화면 가장자리 빛 + 콩알 점프 + 스티커 즉시 발급. 연출 차등이 보상의 절반이다.
- **Pity 규칙**: 귀함 3일, 전설 30일(콩알 꿈 확정 힌트). 희귀 변종(알비노·무늬·황금)은 pity 없음(진짜 희귀로 남김), 거대는 크기 기록 경쟁으로 자연 해소.

### 6-2. 매일의 서프라이즈
- **첫 접속 3단 공개**: ①콩알 꿈 한 줄 ②우체통(편지 1~4) ③게시판(오늘 사건·날씨·방문객). 각 공개마다 짧은 효과음 — 매일 아침 의식(ritual)을 만든다.
- **오늘만 다른 것 최소 1개 보장** 규칙(§1-6 수정 21). 사건 덱이 비면 '조용한 날' 카드 대신 **소소한 변화**(주민 1명 새 옷, 상점 진열 바뀜, 꽃 1개 새로 핌)를 강제 생성.
- 방문객 확률 30%, 단 3일 연속 미등장 시 다음 날 확정.
- **요일 성격**: 월(신문·특가) / 화(꽃 교배 성공률 +) / 수(행상) / 목(주민 부탁 많은 날) / 금(밤 이벤트 확률 +) / 토(대회) / 일(우편의 날).

### 6-3. 편지·우편 시스템
- **편지 종류 7**: 주민 일상 / 답례 / 스토리 아크 / 계절 인사 / 보리 할멈 안내 / 익명(비밀 힌트) / 몽글바람 우편(외부 — 콩떡 고향, 큰솜이 꿈 조각 관련).
- **빈도**: 하루 1~4통(평균 2.2). 주민 친밀도가 높을수록 해당 주민 편지 비중 증가. 결석 후 복귀 시 최대 5통까지 누적(그 이상은 요약 1통 "많이 보고 싶었어요" + 동봉물).
- **답장**: 플레이어는 편지지(15종, 수집)와 문장 조각(선택형 3단: 인사·본문·맺음)으로 답장 가능. 답장 → **1~2일 뒤 재답장**(같은 날 즉답 금지 — 기다림이 보상 크기를 키운다).
- **동봉물**: 답장에 선물 동봉 시 주민 반응 편지에 취향 평가 + 답례(§6-4).
- **편지 보관함**: 최대 200통 보관, 즐겨찾기 무제한, 편지를 가구 '편지꽂이'에 꽂아 집에 전시(편지 3통 선택 표시).

### 6-4. 선물과 답례
- 주민 취향 = **좋아함 태그 3 / 싫어함 태그 1 / 최애 아이템 1**(숨김). 선물 반응 5단계 이모트.
- **답례 규칙**:
  - 즉시: 대사 + 이모트(100%).
  - 지연: **다음 날 아침 소포**로 답례(좋아함 50%, 최애 100%, 그 외 20%). 즉시 답례보다 다음 날 답례가 기억에 남는다(매직 모먼트 3·4).
  - 답례 품질은 선물 가치가 아닌 **관계 단계**에 비례(비싼 선물로 관계 사기 방지).
- **취향 학습 피드백**: 최애 아이템을 처음 맞히면 주민이 "어떻게 알았어?!" 고유 대사 + 비밀 도장. 힌트는 주민 집 인테리어와 대사에 숨김.
- **역선물**: 주민이 먼저 선물을 들고 찾아오는 이벤트(친밀도 3단계부터 주 1회 확률). "그냥 생각나서" — 이유 없는 선물이 애착 형성에 가장 강력.
- **선물 이력**: 주민당 최근 10개 저장, 집 인테리어 슬롯 1~2개에 반영(매직 모먼트 3).

### 6-5. 피해야 할 것 (운영 원칙)
- 연속 접속 보상(스트릭) **금지** — 하루 빠지면 손해 보는 구조는 코지 장르 이탈 1순위.
- 시간 한정 보상은 **1년 뒤 재등장** 원칙(r1 합의 유지). 계절 한정은 "다음 계절에도 같은 품목 재고 판매"로 이중 안전망.
- 일일 필수 행동 ≤10분, 30분 플레이 시 "오늘 할 만큼 했다" 감각 제공(게시판 오늘 카드 전부 체크 시 콩알 "오늘 멋졌어" + 작은 도장).
