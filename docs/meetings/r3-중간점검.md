# 3차 회의 — 중간 점검과 다음 스프린트 (M-b2)

- 일시: 2026-11-24 · 참석: 기획(PD) · 주민·대화(ND) · 월드·생태(WE) · UI·QA(QA) · 총괄
- 오너 요청: "알아서 내부 회의해서 진행" / 오너는 **PC와 폰을 오가며** 플레이·개발한다.
- 입력: 현재 빌드(M-a + M-b 1~6단계), `docs/PROGRESS.md`, r2 회의록 3편

## 1. 현재 빌드 점검 (각 팀 한 줄)

| 팀 | 평가 | 가장 아픈 곳 |
|---|---|---|
| 기획 | 첫날 30분은 원안에 가깝게 재현됨(편지·도구 증정·할 일 카드·도장) | **둘째 날부터 매일 할 일이 약함.** 첫날 카드가 끝나면 목표가 사라진다 |
| 주민·대화 | 3명 × 20줄은 첫 주에 바닥난다 | 주민 수(3)와 '오늘의 대화거리' 부족 |
| 월드·생태 | 변이 6종·영차로 손맛은 됨 | 곤충 행동 3종뿐, 조수 웅덩이 없음 |
| UI·QA | PC·폰 모두 통과. 폰 창 닫힘 버그는 수정됨 | 시스템 폰트(D6), 첫 안내 문구가 잠깐 겹침 |

## 2. 논점과 판정

**논점 A. 다음에 무엇을 먼저?** — 기획: "매일 할 일" / 주민: "주민 추가" / 생태: "생태 다양성"
- 【판정】 r2-재미 느낌 #10 "오늘은 어제와 다르다"와 #14 "아침 의식과 하루 마무리"가 오너 핵심 요구(6개월 매일)와 직결된다. **매일 할 일(오늘의 부탁) → 주민 추가 → 생태** 순서.
- 근거: 주민을 늘려도 매일 할 일이 없으면 대화만 늘어난다. 오늘의 부탁은 주민 수가 늘수록 자동으로 풍부해지는 구조라 먼저 깐다.

**논점 B. 오늘의 부탁 규칙**
- 하루 최대 3건, 만난 주민에게서만. 결정적 생성(같은 날 = 같은 부탁).
- 종류 4: ①아무 곤충/물고기 1 ②이번 달에 나오는 특정 종 1 ③재료·조개 N개 ④**배달**(A의 소포를 B에게 — 우편지기 정체성).
- 보상: 몽 300~900 + 친밀도 +3. 3건 모두 → 반짝 도장 + 콩알 "오늘 멋졌어".
- 벌 없음: 못 해도 다음 날 새 부탁. 받은 부탁은 그날 05시에 조용히 사라진다.
- 부탁이 있는 주민은 머리 위에 작은 「!」. (기획·QA 합의: 폰에서도 한눈에 보이게)

**논점 C. 주민 추가 순서** — r2-재미 §3-2 입주 일정(쫑알 D2, 단추 D3, 호떡 D4, 뭉치 D6, 몽실 D8)
- 【판정】 이번 스프린트는 **쫑알(다람쥐, 수다)·단추(펭귄, 꼼꼼)** 2명. 쫑알이 오면 **쫑알 일보**(게시판 매일 기사)가 함께 열린다. 주민이 4명이 되면 오두막 조건을 원안(주민 4명)으로 되돌린다.
- 입주는 실제 날짜 기준(이사 후 2일·3일째). 이미 오래 플레이한 세이브는 바로 입주.

**논점 D. 폰트(D6)** — QA: 첫인상 차이 큼 / 총괄: 파일 크기·라이선스 확인 필요
- 【판정】 이번 스프린트 마지막. OFL 둥근 폰트 1종을 2,350자 서브셋으로, 실패하면 다음 스프린트로 넘긴다.

**논점 E. GitHub Pages 배포** — 저장소 설정은 오너만 바꿀 수 있다.
- 【판정】 배포 준비(상대 경로·서비스 워커)는 이미 됨. 오너가 원할 때 Settings → Pages만 켜면 된다. 개발은 막지 않는다.
