# 1차 회의 반론서 (r1b) — 월드·맵 2조 + 시간·생태 2조

- 작성: 월드·맵 2조 **가람**(레벨 디자이너, "탐험의 기쁨" 담당) / 시간·생태 2조 **이슬**(박물학자, 생태 시스템 담당)
- 검토 대상: `r1-월드생태.md`(§11이 종 수를 대체함), 참고 `r1-아트.md`, `r1-기획.md`, `BRIEF.md`
- 오너 지시 재확인: **"재밌게, 귀엽게"가 최우선**, 2D로 동물의 숲급 매력, 매일 6개월 이상, 곤충·물고기 기본 200종 × 변이 6, 해산물 80.
- 이 문서의 입장 한 줄: r1은 **"작동하는 시뮬레이터"**로는 훌륭하다. 다만 **"걷고 싶은 마을"과 "잡고 싶은 생물"**이 빠졌다. 생성 규칙과 확률표는 좋지만, 플레이어가 **보고, 놀라고, 손으로 느끼는 순간**에 대한 명세가 거의 없다. 이 반론서는 그 빈칸을 숫자로 채운다.
- 표기: 타일 = **논리 32px**(§1.1에서 결정). r1의 "타일 단위" 수치(속도·도망 반경·충돌 반경)는 그대로 유효하다. 고유 명칭은 기획안(몽글숲·큰솜이·몽글바람·콩알·방울◎·등불 기둥)을 따른다.

## 1. r1-월드생태.md 조목별 비판과 수정안

### 1.1 타일 크기: 16px vs 32px → **32px 논리 타일 + 3/4 뷰로 확정 제안**

**쟁점**: r1은 16px 타일에 정수 배율(최소 2), 아트는 32px 타일 + 3/4 뷰 + PX = scale × min(DPR,2).

| 평가 축 | 16px 타일(r1) | 32px 타일(아트) | 판정 |
|---|---|---|---|
| 아트 헌법 적합성 | 외곽선 1.5px = 타일의 9%. 3톤 셰이딩 하이라이트 타원이 2~3px → 점이 됨. 워블 ±0.4px가 타일 대비 과함 | 외곽선 4.7%, 하이라이트 타원 5~8px 확보 | **32** |
| 캐릭터 비례 | 아바타 40px(아트 기준) = 2.5타일 → 나무 한 그루보다 큼, "거인 마을" | 아바타 1.25타일, 나무 2~3타일 높이 → 동화 비례 | **32** |
| 곤충 가독성(폰) | 곤충 8~14px = 타일 0.5~0.9 → 배율 2에서 16~28 장치px | 같은 8~14px이 타일 0.25~0.45 → 작아 보임 | 16 우세 → **보완 규칙으로 해결**(아래) |
| 화면당 정보량 | 가로 15~17타일 | 가로(세로 화면) 11~12타일 / (가로 화면) 24~26타일 | 32는 세로 화면이 좁음 → **가로 화면 기본 + 세로 지원** |
| 성능 | 화면 내 오브젝트 많음(타일 2.5배) → y정렬·drawImage 증가 | 화면 내 오브젝트 약 40% 수준 | **32** |
| 필레이트 | 동일(화면 픽셀 수는 타일 크기와 무관) | 동일 | 무승부 |
| 캐시 메모리 | 청크당 작음 | 청크당 4배 → 청크 크기 축소로 해결 | 해결 가능 |
| 기존 수치 이전 비용 | — | r1의 모든 수치가 "타일 단위"라 상수 1개(TILE=32)만 바뀜 | **32** |

**결정 제안: 논리 32px 타일, 3/4 뷰, 높이 1단 = 논리 16px(반 타일).**
- 아트는 높이 12px를 제안했지만, **16px(반 타일)**을 권한다. ① 절벽 옆면이 반 타일 격자에 정렬돼 오토타일·경사로 조각이 단순해짐 ② 12px 옆면에는 3톤 + 지층선 2줄 + 하단 AO가 다 들어가지 않음(서로 4px씩 겹침) ③ y정렬 키(`발밑 y + 높이단 × 16`)가 정수로 떨어짐. 아트팀 동의 필요(§8).
- **곤충 가독성 보완 규칙 4개**(16px의 유일한 장점을 흡수):
  1. 월드 곤충 최소 크기 **논리 12px**(XS도 12px, 대신 몸 비례로 작게 보이게 그림). 도감에서 실제 크기 비교는 cm 수치로.
  2. 모든 곤충 아래 **α0.25 그림자 타원 + 날벌레는 0.6초 주기 반짝 1px 링**(풀숲과 구분).
  3. 터치 판정 박스는 그림 크기와 무관하게 **최소 1타일**.
  4. 희귀도 ★4 이상은 **2초에 한 번 작은 반짝 파티클 1개**("저기 뭔가 있다").
- **화면 방향**: 가로 기본(24~26 × 11~12타일 노출). 세로 모드는 scale 0.85까지 허용해 가로 13~14타일 확보, HUD는 하단 1줄로 압축(UI팀 협의).
- **청크**: 16×16타일(512 논리px)은 PX=2에서 청크당 1024²×4B = 4MB → 12장이면 48MB, 저가 안드로이드 위험. **8×8타일 청크(256 논리px → PX2에서 512² = 1MB)**, 화면 근처 + 여유 1칸 = 최대 약 20장, **LRU 상한 24장(24MB)**.
- r1의 "고배율이면 논리 해상도로 굽고 smoothing off로 확대"는 **기각**: 아트가 벡터+AA 방식이라 확대 시 외곽선이 흐려진다(픽셀아트일 때만 맞는 방법). 반드시 PX 배율로 굽는다.
- 맵 112×96타일은 **유지**(32px 기준 3584×3072 논리px). 걷기 4.0타일/s면 동서 횡단 28초, 달리기 17초 → 모바일 피로 허용 범위. 대신 아래 §1.3의 "빈 공간 금지 규칙"을 건다.

### 1.2 지형 생성: 100% 절차 생성의 한계

**문제**: 비밀 장소·랜드마크·경치 좋은 곳은 **설계된 기하**가 필요하다(폭포 뒤 공간, 덤불 틈새, 전망 벤치에서 보이는 풍경). r1의 생성기는 "도달 가능성"만 검증하고 **"가보고 싶은가"**는 검증하지 않는다.

**수정안 — 하이브리드 "스탬프" 방식**
- 수제 프리팹 **18종**(§2.1·2.2)을 데이터로 작성: `{id, w, h, tiles:[...], anchor:'cliffEdge'|'riverBend'|'beachEnd'|'forestCore'|..., minDist:{plaza:12}, required:true|false}`.
- 생성 순서 변경: 지형(해변·절벽·강) → **스탬프 배치**(앵커 조건 만족 지점 중 rng 선택) → 연못 → 부지 → 숲 → 검증.
- 검증 추가: ① 필수 스탬프 12개 전부 배치 ② 스탬프 입구가 BFS 도달 가능(비밀 장소는 "숨은 입구" 플래그 타일을 통과 가능으로 간주) ③ 스탬프 간 최소 거리 14타일(몰림 방지).
- **시작 시 지도 3장 선택**: 시드 3개로 미리보기 지도(축소 렌더 1장당 ~40ms)를 보여주고 고르게 한다. 기획 튜토리얼 3단계 "텐트 자리 고르기"와 묶어 "마을 고르기 → 텐트 자리 고르기" 2단계로. 탈락 시드는 버림.

### 1.3 "빈 공간 금지" 규칙(r1에 없음)
- **관심 지점 밀도**: 통행 가능 타일 어디서든 반경 6타일(≈1.5초 걷기) 안에 관심 오브젝트(꽃 무리, 과일나무, 바위, 일일 아이템, 스탬프, 표지판, 물가) 1개 이상. 생성 후 검사, 위반 셀에는 "소품 스탬프"(그루터기 의자, 돌무더기, 들꽃 무리, 새집 달린 나무) 자동 삽입.
- **12×12 빈 잔디 금지**: 이 크기 이상 연속 잔디가 있으면 숲 밀도 +0.15 또는 들꽃 무리 추가.
- **시야 끝 미끼**: 주요 길이 꺾이는 지점마다 화면 끝에 "보이지만 아직 못 가는" 무언가(섬, 폭포 위 동굴 입구, 등대 불빛)를 1개씩 둔다 → 로드맵 해금 지역의 예고 역할.

### 1.4 높이·절벽
- 절벽 경사로 3개/경계는 적당하다. 다만 **경사로 하나는 반드시 "경치 경사로"**: 올라가면 바로 앞에 전망 포인트(벤치 스탬프)가 오도록 앵커.
- 절벽 아래 **"절벽 그늘 띠"**(폭 1타일)를 서식지 유형으로 추가 → 달팽이·이끼 곤충·버섯 스폰지(생태 연동).

### 1.5 강·물
- 강 폭 3이면 32px 기준 96px — 좋다. 다만 **얕은 여울 지점(징검다리 돌 3~4개)**을 강마다 1곳 보장하자. 다리보다 귀엽고, "건너는 행위"가 손맛이 된다(점프 0.25초, 착지 스쿼시, 물방울 파티클).
- 폭포 웅덩이는 스탬프(§2.2-1 폭포 뒤 동굴)와 결합.
- **강 흐름 벡터**(아트 요청)는 생성 시 랜덤워크 방향으로 저장 → 떠내려가는 꽃잎·낙엽·종이배 연출에 재사용.

### 1.6 오브젝트·리스폰
- **잡초 +3/일, 상한 80은 숙제다.** 오너 지시("귀엽게")와 충돌. 수정: +2/일, 상한 30. 잡초 3종 중 **클로버에 네잎 1%**(뽑으면 다음 1시간 변이 확률 ×1.2 "행운" 버프, 귀엽고 짧게). 부재 복귀 시 잡초 대신 **"반가움 꽃"**(복귀 일수만큼 집 앞 들꽃 피어남, 최대 7)을 피워 "벌"이 아니라 "환영"으로.
- 나무 종을 생태에 맞게 세분: 활엽수 → **참나무 / 벚나무 / 버드나무**(같은 그리기 함수, 잎 모양·색 파라미터만 다름, 아트 부담 최소). 나무 종이 곤충 숙주를 결정(§4.3).
- 바위 8회 두드리기, 코인 바위 → 유지. 단 **바위 아래 곤충**(공벌레·집게벌레)을 바위 치기와 분리: 바위 옆 "들썩이는 돌멩이"(작은 돌, 매일 6개)를 **들어 올리면** 곤충이 나온다(§3.1-D).

### 1.7 생태 데이터
- **귀여움 필터(교체 6종)**: 모기 → **꽃등에**(벌 닮은 파리, 통통함), 집파리 → **하루살이**(물가, 저녁 무리), 꼽등이 → **방울벌레**(가을밤 소리), 갯강구 → **소라게**(해변, 껍데기 갈아입기 연출), 송장헤엄치개 → **물맴이**(수면 빙글빙글), 집게벌레 → **길앞잡이**(길 위에서 몇 칸 앞으로 폴짝 — "길 안내" 연출). 거미·말벌은 유지하되 둥근 디자인, 말벌은 "얼굴 부음" 대신 **콩알이 반창고 붙여주기**.
- **물가 친구 추가**(곤충 도감 안 "작은 친구들" 탭, 기본종 200에 포함): 청개구리, 참개구리, 도롱뇽, 무당개구리, 소라게, 달팽이 2종 → 비·물가 생태의 주인공(§4.2).
- **장소 15유형(곤충) + 서식지 점수 도입**: 장소유형은 "어디서 나오나", 서식지 점수는 "얼마나 자주 나오나"(§4).

### 1.8 포획 판정
- 그물 판정 원(0.7타일) 하나로 200종을 다 잡게 하면 차별점은 "도망 반경 숫자"뿐이다. 행동 10유형별로 **발견 신호·접근 규칙·판정·실패 반응**을 따로 명세(§3).
- 낚시 판정 창: 기획안(0.35초, 희귀 0.25초)과 r1(350~800ms) 충돌 → **r1 값 채택**. 코지 게임에서 0.25초는 터치 지연 포함 시 "운"이 된다. 대신 손맛은 판정 창이 아니라 **찌 연출의 읽기 쉬움**에서 나와야 한다(§3.2).

### 1.9 변이 시스템
- 6변이 구조와 동정 카운터는 찬성. 문제는 **"200종 × 같은 6변이 = 같은 놀람 200번"**.
- 수정:
  1. **희귀 무늬 = 종별 귀여운 모티프 1개**: 하트·별·음표·구름·꽃·달·물방울·리본 8종 중 종마다 1개 지정(데이터 `motif`). "별 무늬 호랑나비", "하트 점 무당벌레". 아트는 무늬 생성기에 모티프 스탬프 8개만 추가.
  2. **계절색에 이름 붙이기**: 봄 "벚꽃빛", 여름 "바다빛", 가을 "단풍빛", 겨울 "눈꽃빛" → 도감 칸 이름이 시가 됨.
  3. **변이 힌트 차등 공개**: 도감에서 해당 종 일반형을 잡으면 6칸이 열리고, 희귀 무늬 칸에는 **트리거 힌트 문장**("비 갠 뒤 무지개 아래서 봤다는 소문이…")을 느림보 박사가 제공.
  4. 황금은 그림자 단계부터 반짝(r1 안 유지) + **황금 포획 시 마을 전체 연출**(하늘에 금빛 꽃가루 3초, 주민 2명이 다음날 축하 대사).

### 2.7 밤하늘 (새 수집 축: "밤하늘 수첩")

## 3. 잡는 재미 — 행동 유형별 상호작용 설계

### 3.0 공통 조작(잠자리채)
- **탭 = 즉시 휘두르기**(준비 0.25초, 판정 원 반경 0.6타일, 중심 1타일 앞).
- **누르고 있기 = 살금 모드**(1.6타일/s, 도망 반경 ×0.5) + 바닥에 **조준 링** 표시. 놓으면 휘두르기(준비 0.15초로 단축, 반경 0.7).
- 모바일 보조 조준: 전방 30° 원뿔, 2타일 안 가장 가까운 곤충으로 판정 중심 0.3타일 자석(설정 on/off).
- 성공 연출: 그물 안에서 곤충이 0.4초 버둥 → 들어 올리기(기획 1-5) → 이름·크기(cm) 팝업. ★3 이상은 첫 포획 시 0.3초 슬로우 + 반짝 링.
- 실패 연출: 곤충이 그물 테두리를 "톡" 차고 나감 + 플레이어 머리 위 땀방울. 경계 ×1.5(r1 유지).

### 3.2 낚시 손맛

**① 던지기(캐스팅)**
- 탭 = 자동 거리 2.5타일(초보). **끌어서 조준** = 1.5~4.0타일, 끄는 동안 점선 포물선 미리보기.
- 비행 0.45초 포물선, 줄이 늘어지는 곡선(베지어 1개), 착수 시 물방울 4개 + 동심원 1개 + '퐁'(음높이는 거리 반비례).

**② 찌 물리**
- 찌 수직 오프셋: 스프링 k=180, 감쇠 c=11(거의 임계감쇠), 물결 입력 = 해당 타일 물결 위상 sin(±1px).
- 물고기 접근 시: 그림자가 찌 방향으로 **몸을 돌리는 0.3초 회전**이 먼저 보임(읽기 쉬움의 핵심). 접근 중 찌에 1px 미세 진동.

**③ 입질 가독성(소리 끄고·색약이어도 구분 가능)**

| 단계 | 찌 이동 | 물결 | 소리 | 진동 | 플레이어가 할 일 |
|---|---|---|---|---|---|
| 툭(nibble) | −2px, 80ms 복귀 | 작은 링 1개 | '톡'(높고 짧음) | 없음 | 참기 |
| 덥석(bite) | **완전히 잠김(찌 사라짐)** 120ms 유지 후 반쯤 떠오름 | 큰 링 2개 + 물보라 | '풍덩'(낮고 둥근) + 느낌표 팝 | 40ms | 지금 당기기 |

- 판정 창: r1 값(★1 800 ~ ★5 350ms, 터치 +80ms, 설정 "입질 여유" +0/+80/+160) 유지.
- **가짜 입질은 최대 3회**, 3회 다음은 반드시 덥석(긴장 과잉 방지).

**④ 끌어올리기(귀여움 담당)**
- 성공 0.6초: 낚싯대 휨(스프링) → 물고기가 포물선으로 튀어올라 **공중에서 한 바퀴 꼬리 치기** → 플레이어 두 손에 안착(스쿼시 0.9/1.1) → 머리 위로 들기.
- 그림자 5 이상 대물: "**영차 연출**" 1.2초 — 물고기가 3번 당기고 플레이어가 뒤로 기울며 발 미끄러짐. 화면에 박자 표시 3개, **맞춰 탭하면 '손맛 보너스' 스티커(실패 패널티 없음)**. 베타에 넣는 미니게임은 이것까지(r1 도현 안과 양립: 실패가 없으므로 난이도 아님).
- 실패: 그림자가 꼬리로 물을 튀기고 사라짐("메롱" 물방울 1개가 플레이어 얼굴에).
- 쓰레기(장화 등)는 "어이쿠" 연출 + 30% 확률로 안에 소라게/개구리.

**⑤ 미끼(베타)**
- 해변 "물 뿜는 구멍"(하루 5~8개)을 파면 바지락 → 미끼 제작. 미끼 던지기: 그 자리에 3초 내 그림자 1개 확정 스폰(서식지 후보 중). 장소 전략성 + 시간 절약.

### 3.3 잠수
- 수영 3.2타일/s, 잠수 버튼 → 1.5초 잠수(r1 유지), 잠수 중 플레이어는 반투명 실루엣 + 볼 빵빵 연출.
- 해저 표시: 잠수 중 바닥 레이어(모래·바위·해초) 밝기 +30%로 "들여다보는" 느낌.
- **거품 크기 = 생물 크기**(S 1개 작게 / M 2개 / L 3개 크게), 거품 간격 = 속도 힌트(빠를수록 촘촘).
- 해산물 행동 5유형: 정지(바닥 반짝), **숨기**(바위 틈에 쏙 → 3초 후 고개 내밈, 그때 잡기), 도망(직선), 지그재그(문어: 먹물 → 0.8초 화면 가장자리 먹빛 비네트, 귀엽게 '퓨'), 따라오기(해파리: 피해야 함, 닿으면 찌릿 연출).
- 잡으면 수면 위로 "퐁" 올라와 들어 올리기. 산소 게이지 없음(코지).

## 4. 생태 상호작용 — "마을을 가꾸면 손님이 바뀐다"

### 4.1 서식지 점수 시스템
- 맵을 **4×4타일 셀**로 분할(112×96 → 28×24 = 672셀). 셀마다 태그 카운트 벡터를 유지(오브젝트 추가/제거 시 해당 셀만 갱신, 저장 안 함).
- 태그 예: `flower.red/yellow/white/pink/purple/blue`, `flower.<종>`, `tree.oak/cherry/willow/pine/palm/fruit`, `water.adj`, `light`(가로등·창문·등불·반딧불 병), `fruit.ground`, `fruit.rotten`(떨어진 지 2일 이상), `rock.small`, `puddle`(비), `shade`(절벽 그늘), `decor.<태그>`(가구 실외 배치), `bare.dirt`, `sand`, `snow`.
- 종 데이터 필드 추가: `likes:[{tag, w, cap}]`, `dislikes:[{tag, w}]`.
- **스폰 가중치 = 희귀도 가중 × 장소 매칭 × 서식지 배수 H**, `H = clamp(1 + Σ min(count,cap)×w − Σ dislike, 0.3, 4.0)`.
- **고갈(셀 단위 피로)**: 한 셀에서 같은 종을 잡을 때마다 그 셀·그 종 H × 0.85, 시간당 +10% 회복(상한 원래 값). → 한 자리 서서 무한 파밍은 막고, **정원 2~3곳을 돌며 가꾸는 플레이**를 보상.
- 플레이어 노출: 생태 수첩 "이 근처에 오는 친구들" — 현재 셀 H 상위 5종을 **실루엣**(미수집) 또는 아이콘으로 표시. 콩알 킁킁과 함께.

### 4.4 변이 "전략 파밍" — 할 수 있는 것과 없는 것
- **할 수 있는 것**: ① 희귀 무늬 트리거 중 꽃색 트리거(r1 §11.6)를 **정원 설계로 상시 충족** ② 서식지 H로 목표 종 조우율 2~4배 ③ 달 위상·유성우·무지개 시간에 맞춰 접속 ④ 미끼로 낚시 회전율 2배.
- **할 수 없는 것**: 황금·알비노 확률 자체를 꾸미기로 올리기(오직 시간 조건 + 동정 카운터). → "노력 = 기회 증가, 행운 = 최종 결정".
- 트리거 확장(r1 8종 → 12종): + 반딧불 병 3개 이상 셀, + 눈사람 옆, + 참나무 3그루 숲 셀, + 썩은 과일 셀.
- 예시 공략(도감 힌트로 공개): "흰 꽃 3×3 + 가로등 1 + 6~9월 밤 = 박각시 조우 ×3, 희귀 무늬(달 무늬) ×5".

### 5.3 해석 — 숫자가 말하는 것
1. **기본종은 플레이 시간이 아니라 달력과 출시가 결정한다.** 30분과 2시간 플레이어의 기본종 차이는 1.5%p뿐. 30분 플레이어가 소외되지 않는 건 장점, 그러나 **2시간 플레이어는 "그날 잡을 수 있는 기본종"을 하루 30분 안에 다 소진**한다 → 남은 90분을 채우는 건 변이·크기 기록·탐험·꾸미기뿐. 그래서 §2(탐험)·§4(생태 파밍)가 "있으면 좋은 것"이 아니라 **2시간 플레이어 리텐션의 본체**다.
2. **r1 합격 기준(180일 기본종 70~82%)은 달성 불가** → §1.11대로 재정의. 6개월 시점 전체 대비 55%는 "1년차 끝까지 할 게 있다"는 오너 목표엔 오히려 맞다.
3. **황금은 30분 플레이어 6개월 9마리** — "가끔 오는 기적"으로 적당. 2시간 플레이어 48마리(400칸 중 12%)는 r1 기준(≤10%) 약간 초과 → 동정 카운터 시작점을 300→400으로 늦추거나 R(★5)=10 → 8 조정 후보.
4. **계절색이 가장 느리다**(6개월 13~22%). 지정 계절을 놓치면 1년 대기 → 이게 2년차 동기. 단 "한 계절만 나오는 종의 마지막 2주 15%"는 놓치기 쉬워 HUD "곧 끝나는 계절색" 알림 필요.
5. 1개월 13%(=약 64종)는 첫 달 하루 평균 신규 기본종 2.1종 → 초반 성취감 충분. 2~3개월(월 +31~46종)이 가장 밋밋 → **2개월차 해금(등대곶·깊은 바다)과 2.8의 신규 지역을 2개월차에 하나 더 당길 것**을 제안(조개섬 3→2.5개월).

### 5.4 정식 `tools/eco-sim.js` 요구사항
- 입력: **실제 데이터 파일**(`data_bugs/fish/sea.js`), 출시 월 태그, 서식지 맵(실제 생성된 시드 20개 평균).

## 8. 남은 이견 (기록)
- **가람**: 높이 1단 16px 주장. 아트(서진) 12px 안과 아트 회의에서 재조율 필요. 가람은 "12px면 절벽이 턱처럼 보여 고지대 해금의 '올라간 느낌'이 약하다"는 입장.
- **이슬**: 서식지 고갈(×0.85/포획)을 베타에 넣을지. 가람은 "파밍 방지는 6개월차 문제, 베타는 관대하게"라며 반대 → **베타는 ×0.92, 로드맵에서 데이터 보고 조정**으로 임시 합의.
- **이슬**: 가짜 입질 최대 3회 고정 vs 종별 성격(의심 많은 물고기는 4~5회). 베타 3회, 로드맵에서 종별 필드 `nibbleMax` 검토.
- **가람**: 별도 맵(안개 연못·동굴·구름 정원)은 본 맵 확장보다 "새 장소 왔다"는 감각이 크다는 입장. r1 한결의 "맵 128×112 확장" 유보안과 충돌 — 본 맵은 112×96 고정, 확장은 별도 맵으로 하자고 제안.
- **공동**: 황금 확률 조정(동정 시작 300→400 또는 ★5 R 10→8)은 실데이터 eco-sim 후 결정.
- **공동 요청**: 아트A(곤충 최소 12px·모티프 스탬프 8), 아트B(스탬프 18종 타일·조수 띠·눈사람·버섯 발판), 대화팀(비밀 장소 소문·큰솜이 잠꼬대 60·펜팔 편지 36), 사운드(입질 '톡'/'풍덩' 구분, 매미 스테레오 패닝, 개구리 합창), UI(조수 아이콘·달 아이콘·"곧 끝나는 계절색" 알림·생태 수첩).
